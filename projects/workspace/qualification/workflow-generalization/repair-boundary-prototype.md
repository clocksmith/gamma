# RepairBoundary: fixture-only first slice

Base: Gamma 47061f703a806bc0c4f1eb0179347fd595729a67. This patch does not run an application, authorize a write, change a default, or launch an experiment.

The prototype takes already observed, successful same-origin GET/XHR JSON with stable source roles assigned by a trusted observer. It mechanically extracts bounded raw scalar fields, not task predicates. It neither selects nor fetches an endpoint. The data minimizer excludes URLs, free text, raw IDs, arrays and credential-shaped keys. No production browser capture or OpenProject source-role adapter is present in this patch.

The learner minimizes distinct scalar field observations, then term count, among conjunctions of literal and field equality terms. It abstains on tied optima, inseparable examples, missing observations, or budget exhaustion. This is an offline, finite-class reference result, not a lower bound on HTTP round trips and not evidence of generalization. One positive and one negative often leave several indistinguishable guards. Ask for a teaching-only contrast or report abstention without inspecting the holdout.

The modular planner has an explicit opt-in trusted callback on all modular action proposals. A refusal, error, or missing checkpoint stops at human review with no fallback planning. Learning is disabled in this guarded planner. An eligible decision is still an ordinary proposal subject to existing review, dispatcher and server checks. The callback must use independently trusted account, record, source and version binding, not model output.
