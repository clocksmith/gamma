# Working JavaScript literal language: 20/20 programs

**The shared language has 79 literal strings, seven bits per selection, and
covers all twenty selected problems.** It uses 154 selections in total. All
20 complete programs were decoded from the actual bit-packed files and passed
all 3,834 independent output/input-preservation checks. No dictionary entry is
a whole program. Fourteen entries appear in multiple programs, accounting for
89 of the 154 selections. The complete counting helper is reused by eight
programs, with all its source bytes stored in the dictionary.

This is working literal assembly of known correct programs. The sequences are
computed offline from the selected sources; autonomous selection given a new
natural-language statement is a separate, untested capability.

## Exact dictionary and packets

[All 79 strings with IDs](packages/shared7/dictionary.json),
[all twenty sequences and bit costs](packages/shared7/manifest.json),
[assembled JavaScript](packages/shared7/assembled), and
[execution evidence](execution/report.json) are included. Literal text contains
actual identifiers, punctuation and whitespace. Concatenation alone reconstructs
each complete source file; no parameters, renaming, dispatch or helper injection
occur during assembly.

The main language costs 1,078 selection bits, plus 50 padding bits across twenty
packets. Its dictionary costs 3,507 bytes, including literal-length framing.
The current independently decodable packet format uses 41 header bytes per
program (magic, width, dictionary hash and selection count), adding 820 bytes.
Total stored dictionary plus packets is 4,468 bytes. Source files and JSON views
are explanatory exports and are not counted as compressed payload.

| Entry budget | Bits | Concrete coverage | Measured representation |
|---:|---:|---|---|
| 16 | 4 | 16/20 in historical bounded search | Incomplete; not an impossibility claim |
| 32 | 5 | 20/20 only in the diagnostic whole-program baseline | Not the claimed shared language |
| 64 | 6 | 20/20 | 61 character literals; 4,214 selections |
| 128 | 7 | **20/20** | **79 shared JavaScript fragments; 154 selections** |
| 256 | 8 | **20/20** | **140 smaller fragments; 813 selections** |

The eight-bit alternative stores only 1,419 dictionary bytes; its dictionary
plus actual packets totals 3,052 bytes. More selections can therefore buy a
smaller dictionary. The seven-bit language is the clearest concrete example of
reusing recognizable JavaScript statements and a complete helper.

Matched controls remain visible: at seven bits, unchanged-source lines use77
entries,141 selections and4,415 total package bytes; at eight bits, the matched
64-merge unchanged-source control uses140 entries,843 selections and2,921 total
bytes. Shared-source rewriting is correct and compositional, but these results
do not establish an overall compression win. The prior dense baseline sweep
remains in [the experiment report](../README.md).

## Anagram equality (#242)

Complete original standalone source:

```js
function solve(values, other) {
    const counts = new Map();
    for (const value of values) {
      counts.set(value, (counts.get(value) || 0) + 1);
    }
    for (const value of other) {
      counts.set(value, (counts.get(value) || 0) - 1);
    }
    return [...counts.values()].every(value => value === 0);
  }
```

Dictionary IDs: `[72, 0, 76, 57, 58, 63, 59, 31, 71, 70, 78]`. **11 selections ×7 =
77 bits**, with 3 padding bits. The packet is 51 bytes including its
41-byte header. Passing checks: **264/264**, including input preservation.

Complete assembled source:

```js
function countValues(values) {
  const counts = new Map();
  for (const value of values) {
    counts.set(value, (counts.get(value) || 0) + 1);
  }
  return counts;
}

function solve(values, other) {
  const counts = countValues(values);
  const result = countValues(other);
  if (counts.size !== result.size) return false;
  for (const [value, count] of counts) {
    if (result.get(value) !== count) return false;
  }
  return true;
}
```

## Longest harmonious subsequence (#594)

Complete original standalone source:

```js
function solve(values) {
    const counts = new Map();
    for (const value of values) counts.set(value, (counts.get(value) || 0) + 1);
    let result = 0;
    for (const [value, count] of counts) {
      if (counts.has(value + 1)) result = Math.max(result, count + counts.get(value + 1));
    }
    return result;
  }
```

## Reproduce

From this directory:

```bash
python3 -B -m unittest -v test_bitpack
python3 -B build.py --output /tmp/literal-working-packages
python3 -B assemble.py packages/shared7/dictionary.ltd packages/shared7/programs/0242.ltv --output /tmp/anagram.js
python3 -B assemble.py packages/shared7/dictionary.ltd packages/shared7/programs/0594.ltv --output /tmp/harmonious.js
python3 -B verify.py --output /tmp/literal-working-execution
```

The codec accepts fixed widths4 through8 and rejects overflow, invalid IDs,
wrong dictionaries, truncation, trailing bytes and nonzero padding. Its tests
compare every supported width across130 sequence lengths, including maximum IDs.
The execution command needs the existing repository Linux Node/bubblewrap judge;
expected values remain outside the sandbox. No training or downloads are needed.
