# Explicit Python reference-compatibility probes

These independently executed Python sources are probes of defined admitted
reference behavior on the unchanged frozen cases, including inputs outside the
normative author-declared problem domains. They are NOT normative repairs, domain
reconciliation, original source passes or automatic M1/dictionary admissions.
`qualified` remains zero; `compatible` and `compatible_ids` describe only finite
reference compatibility. The normative-domain status remains unresolved.

Each source manifest explicitly chooses a fixed subset of either the authorized
300 dev-fit or100 consumed dev-val partition. Never mix them, open protected
final100/protected66 or shrink the frozen500 denominator. Dev-val sources and
observations never enter dictionary fitting or proposal feedback. Existing sources,
case data, expected outputs, old failures and source/runtime contracts are retained.
Source changes are separately versioned and frozen before fresh replay.

A probe may implement independently understood reference semantics, including
specified range-specific or malformed-input behavior, but cannot embed expected
outputs/case lookup. All source, arithmetic/encoding helpers, constructors, imports
and entry code are explicit and fully charged. Reference-source hashes bind the
behavior being probed. Unsupported semantics fail, rather than silently guessed.

Direct solve sources execute through the unchanged Python sandbox:3CPU/8wall
seconds,1GiB,4MiB output,32cases per isolated call. Expected outputs remain host-only.
The explicit Python type/integer/node/alias bridge and independent host oracle
remain unchanged. Fresh returned observations must satisfy both frozen expected
results and complete historical effect/type parity. Independent verification
replays every raw observation and preserves failed compatibility checks.

A later source-pool consumer must make any use of compatibility-only evidence
explicit and keep it separate from normative M1 correctness. This runner itself
makes no vocabulary choices and grants no fitting/admission authority.
