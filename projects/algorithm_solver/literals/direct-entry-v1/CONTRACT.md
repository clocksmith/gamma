adapter to strict direct-entry transformation. Helper bytes and method-body bytes

qualified variants remain available; they are not counted as newly qualified
lowered sources. This revision does not rename bindings, generate algorithms,
inline helpers, rewrite expressions, or fit any literals. It claims ordinary
frozen judge-call equivalence, not arbitrary function/class reflection equivalence.

the existing pinned Node isolation, original typed/exact transport, unchanged
host expected-value oracle and complete historical type/mutation/alias/error

qualification code hashes. Verification regenerates the lowering from the exact
prior qualified sources using the receipt-verified trusted AST parser, checks
exact emitted bytes, and independently replays all retained observations. Pass
flags and AST flags alone never confer source eligibility. Full helpers and
lowered source bytes are charged in the later vocabulary representation. Complete
helper solutions remain forbidden literal entries despite reuse.
