## Proposed bounded flat experiment

Use exactly the existing A allowlist: fit300 and consumed validation100. Start
from13 scope_joint256 dictionary/source hashes and originalR. Never call the
old all500 pool loader. Final100 and protected66 stay closed. Fit controls and
candidate dictionaries seal before any new validation generation or encoding.
Do not choose which stack to evaluate using newly measured validation results.

Four source trajectories establish source-factor attribution:

| Arm | Source proposals | Dictionary work |
| --- | --- | --- |
| N | Ordinary13 a-z binding continuation | Existing v3 local search |
| NC | N plus14 coupled proposals | Same local search caps |
| NP | N plus10 compiler variants | Same local search caps |
| NCP | N plus both coupled and compiler proposals | Same local search caps |

The source factorial identifies NC−N, NP−N, NCP−NC and NCP−NP. Their differences
are complete bounded pipeline effects; compiler/coupled costs are additional
work and must be reported, not described as equal CPU merely because caps match.
Every arm retains originalR,13seed and its prior selected source. No program
may select another arm's validation result or a per-program best dictionary.

Two fit rounds per trajectory. In each round, generate the frozen compiler
profiles only from the current selected source (NP/NCP), retaining prior
selected variants. Rebuild lexical records for every changed compiler output, rather
than reusing stale spans. For each retained current-round compiler alternative,
run ordinary binding descent; NC/NCP also run coupled descent. Retain original
candidates and choose under exact canonical minimum selections, then source
byte count, then source text. Audit full solve/body exclusion and reparsing
before dictionary search. Local search reselects from the retained variants.
This is supplied-source offline optimization, not autonomous assembly.

Limit one program to the original plus seed, retained prior selected variants,
and three current compiler outputs (layout, syntax, standard); deduplicate exact source hashes
before naming. Pin their exact options from10, never add a profile
because of a failed task. Bound naming to two sweeps/6000 scored trials per
input candidate; coupled to its existing3rounds/512proposals/100000states.
Retain at most the originalR, seed13, two prior selected round sources,
three current compiler outputs and their three named outputs, plus the current
selected source and its named output:12slots before hash deduplication.
For a collision retain the earliest declared provenance. Never prune original,
seed or previous selected sources; there is no score-dependent truncation.

NCP's final selected fit sources are the PREDECLARED source cohort for deeper
stacking, irrespective of which source arm later looks best on validation.
Freeze those source bytes; the next stage does no naming or compiler adaptation.
This gives four dictionary continuation arms without four repair trajectories:

## Structured stack sidecar: separate goal2c

Use D11's exact fit/validation source cohort and dictionary as the predeclared
base, irrespective of validation outcomes. Fit four bounded representations:
literal-only, prefix-only, identifier-template-only, and both. All start with
one <=256entry budget; constructor entries displace literals and every child or
distinct identifier argument costs a code. Mine both pools on fit only, with
shared-source support and existing whole-body/per-use guards. Same300seconds/
10000trial cap per representation. Report common fixed-source costs, eligibility
before selection, and outcome-dependent usage separately. If a source itself
failed qualification, it stays failed in every sidecar and blocks readiness.

The combined grammar is a NEW isolated2c codec, not a concatenation of packets
or two free dictionaries. Use explicit charged entry tags L/P/I. Prefix nodes
retain their existing recursive expression grammar (depth at most8), while an
identifier template is a nonrecursive span with literal-only identifier args.
For the first union design, allow P and I as alternative top-level source-span
edges; do not nest I inside P or create new mixed recursive expansions. Body DP
chooses nonoverlapping spans, charging all emitted IDs. This is a bounded union
of proven mechanisms, not the strongest possible combined grammar.

Independent decoding must validate arity, Identifier spans, root shape, exact
source bytes and per-use whole-solution exclusion; malformed metadata fails
closed. Serialize the entire mixed dictionary and all decoder dependencies.
No item20 metadata is free because13 already selected a similar string.
Literal-only and separate-prefix/template ablations use the same proposed pool
and search accounting but only their declared entry kinds. Canonical-only and
minN/minC policies must be matched within each comparison; if the new typed
encoder does not implement minN/minC, compare typed CANONICAL with the base's
CANONICAL shadow, not its primary minN/minC row. Clearly label that comparison.

These are 2c input-readiness results only. A lower structured action count or
character share cannot satisfy flat-literal M1 by changing representation labels.
Keep the flat M1 gap ledger untouched by a structured-only result. This sidecar
is a separate executable phase under the same umbrella freeze and must not
delay the source factorial if its decoder needs more implementation work;
freeze any staged phase boundary explicitly before either phase launches.

## Qualification, acceptance and selection

All400final flat source choices seal before any case execution. Deduplicate
source/hash/contract/runtime identities across arms. Reuse only exact pinned
qualified hashes (e.g.15seed receipts); execute every new final source against
all original cases with strict observation parity and unchanged sandbox limits.
Retain historical23 failure; do not count an old passing hash as a new successful
execution or retry a failed new choice. Qualification failure means failure
for every arm using that source. No test feedback, fallback replacement, repair
or relaxed limits. Every packet independently decodes; structured sidecars
reuse the exact source qualification, not a second round of test-informed fitting.

For each eligible flat candidate require all400fit/validation qualification,
100/100validation coverage, <=256entries and clean whole-source/body audit.
Require existing readiness against matched-policyR: >=5%fewer actions, strictly
lower median/p90, >=60better and <=25worse, nonincreasing character fraction,
raw package <=105%. Then require strict fewer validation actions versus matched
seed13 and N, with median/p90/fraction nonincrease, <=25worse and package<=105%.
D candidates must also satisfy those incremental checks against NCP; D01/D11
must additionally beat their same-repair w0 control. These constraints prevent
a source improvement alone from hiding a regressive added component.

Use only candidates passing ALL predicates in ranking: fewer actions, then
smaller raw package, then lower character fraction, then fixed arm-name order.
If none pass, retain24 as selected. Report each failed predicate and all paired
counts, not only the best total. The structured sidecar uses separate2c
readiness versus its matched literal sidecar and source-seed reference; its
selection never displaces the flat candidate by relabeling.

Report selection and action quantiles separately, absolute C and C/N, source byte
changes, input/header/padding/dictionary bytes, decoder-inclusive and one-program/
amortized costs. Count compiler/rewriter/MILP/typed-encoder dependency bytes and
offline compute separately. Installed runtime footprint is unknown unless
measured. No net-byte or timing victory from excluding the new decoder.

M1 thresholds remain400/500coverage,<=256entries,median<=32 and p95<=96 selections,
<=10%character bits,zero whole-solution entries. Development readiness does not
establish those gates. Dictionary continuations alone on unchanged13 sources
cannot evade25's declared-pool certificate; the new source factorial and2c
sidecar change its premises, not its validity. No universal impossibility claim.
