# Dated note, 2026-10-23: v1 superseded before any run

[FREEZE.md](FREEZE.md) is unchanged, and nothing under `lagrange-select/run-v1` was produced.
Codex's review (gamma-team LOG, 17:56Z) found three problems:
- `lagrange()` kept the baseline as its primal unless a generated dictionary beat it. So
  `global_raw` could never be worse than the baseline, contradicting prediction Λ3, and a worse
  generated start would never have been polished.
- The integer ceiling of a floating-point bound was presented as certified.
- The motivation claimed that capacity is the binding limit, which A does not establish.

The successor is [lagrange-select-v2](../lagrange-select-v2/FREEZE.md). It keeps the generated
primal apart from the incumbent, certifies the bound with exact integer arithmetic, and corrects
the motivation. The v1 files stay in history at `4ca4bdc6c`.
