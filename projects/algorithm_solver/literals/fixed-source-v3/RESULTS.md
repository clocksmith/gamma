# Fixed-source comparison v3: results

Run `fixed-source-v3-r1`, frozen in [FREEZE.md](FREEZE.md) before any v3 dictionary was built on the real corpus. This file is generated by `make_results.py`. Sources, dictionaries, parses and solver output stay private.

**Decision.** The frozen kill bar passed, and it still passes with equal search floors. A full paper may proceed only if the prior-work comparison also holds.

**Greedy against the main baselines.** Passing K2 does not mean greedy beats BPE or PathPiece. Under the primary rule, greedy is smaller in raw table: 144 of 144 cells against BPE, shortest parse, 87 of 144 cells against PathPiece; bpe merge pairs: 117 of 144 cells against BPE, shortest parse, 87 of 144 cells against PathPiece; compressed dictionary, all arms: 144 of 144 cells against BPE, shortest parse, 60 of 144 cells against PathPiece.

**Predictions.** 2 of 5 held. Failed: V1, V2, V3.

Everything here is in-sample on 400 paired Python and JavaScript solutions, with exact reconstruction. It says nothing about unseen code or model quality, and it claims no new algorithm or certificate. The certificate used in v1 and v2 is Theorem 1 of [Du and Chen](https://arxiv.org/abs/2609.35869).

**Run note.** The LP stage reached its frozen 3-hour limit, so the pipeline stopped before verification. Unfinished LP solves: s2-nowhole K=1024, s2-nowhole K=4096. As the freeze requires, the run reports what finished: verification, regression, encoded sizes, scoring and the post-hoc checks were then run with the frozen code and commands (`finish.log`). The chain stage finished within its limit.

## Boundary-crossing ablation

At 1,024 entries of up to 16 bytes, forbidding any piece from spanning a change of lexical class moves design A from 85,049 to 116,344 bytes, a 36.8% change. This explains where savings come from and has no part in the kill bar.

## What this does not show

- Nothing here measures unseen code, a trained model or runtime speed.
- All dictionary searches are heuristics, and no cell has a proved optimum.
- The parser minimizes tokens, not bytes, so a byte-optimal parse could change these totals.
- PathPiece and GreedTok are our implementations of the published methods.
