# Initial Python systematic source-as-data fit

The initial supply is the exact 272 independently replayed complete Python sources
from the all-300 adapted run. The remaining 28 fit problems are explicit gaps;
no denominator is silently shrunk to claim M1. The 100 consumed development
validation programs are excluded from fitting; protected cases remain closed.

Policy is fixed before fitting: independent 128/7 and256/8 branches, each starting
from the96 literal characters, first local family vocabularies of up to32 learned
entries, deterministic maximum-overlap merges and exact redundancy removal, then
coupled adjacent-fragment composition with optional retirement of learned parents.
The exact gate-bound optimization may skip only provably inferior candidates, not
arbitrary top-K proposals. No source cost feedback changes AST family labels.

Initial CPU slices are240 seconds per branch, outer330-second wall timeout and
2 GiB address-space bound. Slices preserve ledgers and can resume the same frozen
policy; a paused slice is not convergence. Both branches have identical slice
budgets. Each accepted state includes exact source choice and independently
recomputed segmentation/decode/storage/framing/decoder costs. No candidate source
is executed in this fitter.

**Conservative first-run restriction, not a change to M1:** complete helper
functions/classes/bodies are initially excluded in addition to whole solutions.
Generic helpers may be legal under the original rules when they cannot encode an
entire admitted algorithm behind a trivial wrapper. A future linked, separately
reviewed exact-byte Python primitive allowlist may admit such helpers without
resetting the vocabulary or rewriting this first-run evidence. No JavaScript
helper allowlist is silently transferred to Python.

The trusted trie kernel was checked against the original Python DP on all272
qualified source rows under two dictionaries (544 exact row comparisons), in
addition to inherited random/tie/prefix tests. This is scorer equivalence, not
candidate correctness evidence or an optimization result.
