# Python-only literal supply and systematic vocabulary v1

This new lane uses Python implementations, a Python interpreter, Python-qualified
raw observations and exact Python source bytes only. JavaScript qualified receipts
never admit Python source. Reuse of the language-neutral dictionary DP/codec is
trusted source-as-data computation, not execution or cross-language solution code.

Source freeze appends and fully charges a literal `def solve(*args)` wrapper calling
the authored `Solution` method. Every original byte remains, including helpers,
class boilerplate, comments and whitespace. Fresh isolated execution invokes this
exact solve entry; unused/inferred adapters do not qualify. Python runtime, numeric,
type, mutation and alias contracts are inherited explicitly from
[Python replay](../python-replay-v1/CONTRACT.md), not its pass flags. Native limits,
host-only expected outputs, complete raw observations and independent replay are
unchanged. Earlier failed attempts remain preserved.

Only independently verified fit-source variants may enter fitting. The initially
available JSON-evidence subset is 234 of the fixed 300 fit problems, not a newly
chosen population or 400-program claim. The other 66 fit problems and 100 consumed
dev-val problems remain explicit coverage gaps until their Python qualification.
The full denominator is 500. Final100/protected66 stay closed. No validation text
or cases enter proposal generation, family classification or dictionary fitting.

The shared literal alphabet remains 95 printable ASCII characters plus newline;
Python indentation is ordinary, fully charged source, not a hidden formatting
operator. Unsupported source characters fail closed. Entries are exact strings:
no operands, AST expansion, macros, external helpers or hidden code channels.
Python AST spans exclude any complete source, class, method, function or complete
function body from individual literals, including a wrapper around a whole body.
A complete primitive is not automatically whitelisted. Every learned entry needs
witnesses in at least two distinct qualified problems, not two alternatives.

Frozen families derive solely from Python AST structure before source cost feedback.
Local growth, deterministic overlap merging, exact redundancy removal, adjacent
fragment composition with parent retirement, joint source reselection and safe
exact gate-bound pruning reuse the systematic policy. All accepted states retain
hash-linked choices, complete costs and independent two-segmenter/decode checks.
128/7 and 256/8 remain matched capacities. Every helper, source wrapper, dictionary,
framing, padding and decoder byte is measured. No fit may start before exact adapted
source eligibility and an explicit frozen algorithm/budget contract exist.
