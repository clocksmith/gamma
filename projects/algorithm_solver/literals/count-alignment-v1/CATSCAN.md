# CATSCAN: Integer-count source alignment

Parent: [Algorithm Solver](../../CATSCAN.md)

## Target

Measure source-informed count helpers and finite correct-source alternatives under goals 2a/2b, preserving separate input, storage and readability objectives.

## Authority

Owns this bounded rewrite mechanism and aggregate experiment record. Existing corpus admission, isolated judging and publication authorities remain unchanged.

## Scope

Four source-hash-guarded witnesses for two exposed development problems, two languages, three optional complete helper strings, and 6/7/8-bit encoding controls.

## Contracts

- Input: an explicitly provided, already reviewed external witness file and the pinned existing `algsolve/synth/components.py` registry.
- Output: a separately stored successor with exact expected identity. The [evidence summary](evidence.json) distinguishes historical full-program qualification from portable-tool tests.

## Invariants

No source execution by the rewrite CLI, hidden helpers, whole-program dictionary entries, uncounted source parameters, private test exports, ledger writes or automatic admission. Preserve predecessor alternatives and all original domain diagnostics. Treat test results as bounded evidence. Increment depends on read at runtime; dictionary text overlap is a separate relationship.

## Acceptance

Focused [synthetic tests](test_rewrite.py) check identity/span guards, exact separators, registry integration and output preservation without private witnesses. Historical source-bound execution and independent encoding audits are pinned in the evidence summary. The unexecuted 258-case primitive suite cannot be represented as passed.

## Non-goals

A general AST-equivalence engine, standalone primitive qualification, a global optimizer, human-usability evidence, M1 achievement, hosting or new admissions.

## Freedom

Implementation may change if it preserves these boundaries, measured identities and explicit cost objectives.
