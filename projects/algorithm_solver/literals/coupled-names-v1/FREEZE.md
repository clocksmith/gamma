# Dictionary-guided coupled names

Board14, goal2b. Item13 scope_joint256 passes consumed-development readiness;
its dictionary and selected sources are the frozen seed. Coordinate substitutions
and pair swaps can miss improvements requiring two or three different names at
once. This stage adds finite dictionary-guided proposals to continued ordinary
descent. It does not confirm item13 or change M1.

## Population and controls

Use only the same qualified R fit300/validation100 allowlist. All validation is
consumed development; held-out100/protected66 stay closed. No corpus proposal,
cost or eligibility run preceded this freeze. Nine synthetic tests cover two/
three-name barriers, repeated-binding consistency, complete identifier spans,
simultaneous swaps, capture, whole-body rejection, caps and reflection guards.

Six 256-entry/eight-bit arms: historical `control` and item13 `seed` replayed from
hash-bound artifacts, `ordinary`, `coupled`, `ordinary_joint`, `coupled_joint`.
New arms start from item13 scope_joint256 dictionary and selected fit sources,
retaining R and seed alternatives. Two rounds each: ordinary descent (item13
scope policy, two sweeps/6000 scored proposals) in both mechanisms; coupled arms
then add the proposal procedure below. Joint arms refit the dictionary with
matched80-v3 refill/swap/pair search, 30000 trials or600 seconds each round,
refill shortlist24 and the pinned neighborhood. Fixed arms keep the seed dictionary.
Dictionary proposals use selected-owner spans, require two owners, exclude all
observed complete sources/solve definitions/bodies, and retain96 fallback characters.

Seal fit choices and dictionary before loading validation source values. Choose
between original R and item13 seed validation text under the sealed dictionary
by selection count, bytes, then text; run two naming calls with the same policy
and no dictionary refit. The seed validation texts themselves were produced
under item13's fit-sealed dictionary, not validation-trained parameters. This
is continued source-plus-encoder development, not an independent replication.
Historical controls incur no new optimization; new ordinary arms measure the
benefit of continued search, and coupled-vs-ordinary measures added operator
availability with explicitly additional evaluation work. Joint trajectories
can diverge. Report both historical and continuation comparisons.

## Exact coupled operator

Reuse item13's capture graph, fixed bindings and reflection/non-ASCII retention.
No printing, property changes, arithmetic/control changes or model calls.
Build a trie of dictionary entries of length>=2. For each source position not
inside an eligible binding span, traverse fixed characters exactly. At a complete
eligible span, consume its unchanged name or a-z and jump past the entire original
span. Repeated occurrences of a binding within the match must take the same
name. Only terminal matches changing two or three bindings propose a full-program
assignment. Check all graph edges, fixed and unresolved-name constraints after
the simultaneous assignment, so temporarily colliding swaps are not rejected.

Deduplicate by sorted binding-ID/name assignment. Rank proposals by descending
matched dictionary-entry length, earliest source start, dictionary ID, then
assignment tuple. Traverse starts ascending and targets lexical ascending using
a depth-first stack. Each pass allows100000 visited trie states; report cap and
preserve proposals discovered before it. Score at most512 ranked proposals.
Before scoring, reject assignments making any dictionary entry equal the complete
source or top-level solve definition/body/trimmed block contents (the same body
categories as tail-search). Apply that legality guard to ordinary trials too.
Score the full rendered source with canonical shortest segmentation. Accept only
strict selection improvement, tie by source bytes then text; apply the best
proposal once and regenerate. At most3 coupled passes per call, stopping when
none improves. No ordinary refinement after those passes until the next call.
Report ordinary/coupled exact scores, proposals, visited states, caps and moves.
The ordinary trials and additional coupled work are not equal-compute arms.

## Evidence and cost

Original and prior alternatives remain available at fit selection. Audit all
retained fit/validation variants for whole-source/body entries. Independently
decode all2400 final choices. After every final choice seals, independently
execute distinct changed source/ID pairs on all original frozen cases with strict
observation parity; unchanged R reuses hash-bound qualification. Failures remain
failed choices with no repair, retry or test-driven fallback. Finite checks do
not prove general equivalence. All source/dictionaries/mappings/traces/cases stay
private; publish only sanitized metadata and hashes.

Report source bytes, coverage and qualification; selection/action total, median,
p90,p95,worst and <=32/96; absolute single-character codes and fraction; paired
better/same/worse; dictionary/packet/framing/padding and decoder-inclusive package.
One Finish per program, unchanged canonical dictionary/decoder and bit width.
Scope/parser/rewrite code is offline encoder storage; full runtime installation
footprint remains unmeasured. Resource ceilings: four search workers then four
sandbox workers, cores0–7,4GiB per process,7200 seconds globally,PYTHONHASHSEED0.
Report all stops; bounded/local search does not prove an optimum.
