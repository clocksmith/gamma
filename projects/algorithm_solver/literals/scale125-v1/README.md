## Search budget and conclusion

One worker,≤4 CPU threads,8 GiB RAM,256 MiB artifact cap; no GPU or downloads. Each width permits two rounds, at most 504 legal dictionary moves plus 96 addition-ranking probes (600 total),and 120 seconds. Candidate proposals combine AST snippets and encoded spans with distinct-problem support. Exact resegmentation/reselection ranks proposals; stored dictionaries never exceed the cap. No new source or case tuning occurs during search.

Seven-bit search uses 92 legal moves plus 47 ranking probes in 2.68 seconds; eight-bit search uses 220 plus 47 in 5.05 seconds. Both stop for no improvement in the tested neighborhood, not exhaustion of all possible dictionaries. Total measurement/audit-path time is 8.40 seconds; independent audit is separate. Raw artifact bytes are approximately 23 MiB (filesystem allocation 39 MiB), within cap.

Next stage decision: retain the current dictionaries, then freeze a separate 125→150 panel from the 28 reserved development IDs before accessing their source/cases. Measure frozen expressibility first, followed by independently qualified source normalization and bounded relearning. Report the original 100, this 25 and the next 25 separately. Do not begin that stage implicitly in this run.
