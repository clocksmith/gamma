# Dated note, 2026-10-23: v1 superseded before any run

[FREEZE.md](FREEZE.md) is unchanged, and none of its runs executed: no real-route comparison,
and nothing under `runs/facet-gate-real-dev-128-v1`.

Codex's review (gamma-team LOG, 17:23Z and 17:26Z) found these defects in v1:
- **Nested negation:** "it is not true that there are no fees" was read as a no-fee fact.
- **Absence defaults:** they let silence, or a grammar non-match, settle an answer-changing
  facet.
- **Empty required-facet lists:** they were justified by the absence of an indexed sibling,
  which is the rank-failure mechanism.
- **No pre-run hash check:** the driver never checked that the files it ran matched the frozen
  ones.

The successor is [facet-gate-dev-128-v2](../facet-gate-dev-128-v2/FREEZE.md). It has a strict
candidate, keeps the defaults only as a labelled ablation, adds per-source completeness review,
and adds a manifest check before inference. The v1 files stay in history at `0ba7d8c0a`.
`algsolve/facet_gate.py` has since changed for v2, so v1's pinned hash refers to that commit.
