# LCD recognition reconstruction: bounded development pilot

`recognition-rebuild-dev-suby-v1` completed on suby using the approved pinned
encoder and LCD training payloads. This is a new development reconstruction,
not the historical 3,353-entry service, fresh confirmation or learned composition.
[Aggregate receipt](summary.json) binds the candidate, runner sources, download
identities, resource counters, per-case dispositions and reproduction commands.
Raw data, code answers, tests, weights and full route receipts remain ignored
and local; none is redistributed in this finding.

## Result

All 16 target references passed fresh isolated source qualification: 39 public
cases, 1,418 imported independent cases, and all 16 executed exact-answer paths.
The description pilot then returned **7/16 specified answers correctly**, with
zero wrong acceptances and zero unqualified acceptances; nine abstained. Its
seven returned programs passed 557 further source-suite test executions after
all 24 public decisions were sealed. These are finite source-test agreements,
not newly authored independent query or benchmark-judge evidence.

|---|---:|---:|---:|---:|---|
| Specified descriptions | 16 | 7 | 0 | 9 | 0.777 / 0.937 seconds |
| Underspecified descriptions | 4 | 0 | 0 | 4 | Below 0.00002 seconds; pre-retrieval gate |
| Out-of-domain controls | 4 | 0 | 0 | 4 | Below 0.00003 seconds; pre-retrieval gate |
| All requests | 24 | 7 | 0 | 17 | 0.727 / 0.920 seconds |

The eight control requests lacked public examples and abstained before retrieval.
Their results do not establish semantic ambiguity reasoning or genuinely absent
algorithm recognition. Zero questions were asked. Specified fixtures use the
existing authored description text plus newly supplied target-source public
examples, with no target identity, starter, parameters or oracle signature passed
to the answer engine. Added public information and the reduced index mean these
numbers are **not matched improvement over the old description-only baseline**.

## Fixed inputs and scope

Only the five approved files were downloaded: **1,296,663,981 bytes**, verified
in 35.72 seconds. Encoder revision `97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3`
exactly matches the frozen weight and tokenizer hashes. LCD revision
`215604aeed660029df7de2fea5a4d7b6ed476a08` has new reconstruction provenance.
Qwen's Apache-2.0 label and LCD's HF Apache-2.0 / linked GitHub MIT discrepancy
are retained locally with source attribution. Data remain local research inputs.
No additional dataset, generative model, dependency or composer was downloaded.

The index rule was frozen before execution: union the old development shortlists
and their 16 expected identities, yielding 83 requested keys. Metadata exclusions
remove protected identities, sibling families and recorded aliases before
signature parsing, indexing or qualification. Of 2,641 LCD training rows, 65
were excluded by that boundary and 2,510 were outside the frozen shortlist.
The index contains 66 entries, including every target. One requested key was
excluded by the boundary and 16 lacked a permitted training-source entry. Only
16 target sources are qualified; other candidates stay visible but unapproved.
No rejected candidate is silently replaced by another answer. Thresholds and
sibling guards are unchanged.

## Costs, preservation and next work

The pilot took **240.05 seconds wall time** and **789.80 process CPU seconds**,
with four CPU cores/threads, **3,980,046,336 bytes observed peak aggregate RSS**
(0.1-second sampling), and **1,298,382,007 bytes** in the monitored asset/run
roots at reporting time. All stayed inside the approved 8 GiB RAM / 5 GiB disk
envelope and the first-pilot 900-second wall cap. Encoder loading plus hash
verification took 6.338 seconds. Warm route costs include embedding, retrieval,
filtering, assembly and public checking; imports, source qualification, index
setup and independent scoring are outside those per-request timings. The host
was shared; no exclusive-host or cold-machine performance claim is made.

Thirty focused software tests and 15 subtests passed. They are separate from
the actual isolated qualification, encoder inference and returned-code scoring.
Completed-run resumption verified all **208 artifact contents and mtimes**
without repeating encoder inference or judging. Immutable candidate and stage
hashes reject source, data or receipt drift.

Nine specified abstentions remain: four confidence failures, two unresolved
sibling margins, two public-check rejections and one unapproved top candidate.
The next selector experiment should compare explicit requirements on the same
fixed development corpus and inputs under a new candidate seal, retaining this
control. This pilot does not pass any independent 1a/1b release gate. No protected
set was opened; the original composer checkpoint/corpus remain missing and no
composer training or replacement experiment was started.
