# New local composition development corpus

`typed-lcd-suby-development-v1` is a separately identified LCD-only corpus,
prepared on suby from the already approved local training snapshot and the
existing authored typed-development proposals. **24/24 graph labels across
18 problems qualified**, passing 57 public cases, 2,975 independent cases and
24 declared-bound probes. This is teacher-label qualification, not neural
prediction or autonomous solving. [Aggregate receipt](summary.json) and
[pre-execution contract](contract.json) bind source, data and exclusions.

`566d6b440d7fdd16bac0b86114b5e8dd35ba8bd646b6bd304f8cfbc5e201330e`
and `typed-student-v2` checkpoint remain missing. This corpus is not either
historical artifact and was not saved under their identities.

Metadata exclusions precede signature/source/test parsing. They include the
protected reservation and recorded aliases, solving identities/families and
recognition families. Only the 18 previously permitted proposal identities are
selected. No protected graph, source test or scoring variant was opened. The
codec remains `e91aee58994ae952e2b43406606127689e10688404f2b5c774380dc7a77df7ad`.

process-tree RSS and 1.304 GB in monitored asset/run roots, on four CPU cores.
No model was loaded or trained. Source, tests and graph-bearing artifacts remain

corrected before any qualification execution. This software evidence is separate
