# Authoritative-document development successor

This prospective experiment retains all 4,081 title competitors and fixed twenty
threshold policies/selection rule. Fifty-four independently reviewed normative
contracts supply deterministic semantic fields; 4,027 exact unchanged title vectors
are reused only under pinned original encoder/tokenizer/pooling adapter, model and
CPU identities. Batch size remains four. Availability is consulted only after full
ranking. Knowledge asymmetry remains explicit; this does not establish open-world
semantic identification or population risk.

The same authored, non-IID 52 development queries are reused after the failed
historical title-only development iteration. There is no confirmation CLI or path.
The sealed cohort is not opened. Historical results/resources remain unchanged.

All 54 changed documents and 52 query embeddings have separate persisted,
hash-bound vector caches, text bindings and exact tokenizer metadata. Any truncated
index document blocks a full-index result; a truncated query abstains. Every policy
reports absolute correct/error/control acceptance and abstention counts. The final
selection is still the prior frozen rule. No training, downloads or GPU use.

Proposed resource envelope: 300 CPU seconds (305 hard), 240 seconds wall,
8 GiB address space, two threads, at least 5 GiB available memory before loading.
An outer native process-group timeout/cleanup remains required. Main/root review
must approve the private exact freeze before launch. Tests execute synthetic
metadata only; no encoder is imported by tests. This is a delta run, not a cold
end-to-end 1c measurement.
