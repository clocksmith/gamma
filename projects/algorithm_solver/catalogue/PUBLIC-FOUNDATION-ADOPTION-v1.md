# Prospective official-domain adoption

`public_foundation_adapter.py` deliberately adopts the separately reviewed public
foundation qualification for 153, 645, 674, 832, 833, 916 in both languages. It replays
all frozen public raw observations through the independently reviewed host oracle
before constructing source-specific normative receipts. This is not relabeling an
old admitted or compatibility receipt.

The successor retains the complete 4,081-ID universe and all 166 protected identities
byte-for-byte. All 772 predecessor receipts remain unchanged. Six JavaScript
canonical sources retain identical bytes but gain separately scoped normative
receipts; six existing Python solve-adapted sources gain their first reviewed
in-domain canonical qualification.

Current canonical coverage is 400 JavaScript / 378 Python: six normative artifacts per
language, 394 admitted JavaScript and 372 admitted Python artifacts. 378 permitted IDs
return both languages; 22 permitted Python gaps remain. These counts do not mean
full 4,081 coverage, informal-recognition qualification or historical M1 completion.

Each new normative artifact and receipt binds:

- official numeric identity, source attribution, typed preconditions and result;
- exact ordered `solve` parameters and local effect profile;
- source bytes, runtime, isolation/resource policy and per-problem public tests;
- oracle/input-validator, harness and independent-verifier code identities;
- pre-execution clause/source/local-policy review and 153's separate logarithmic
  interval-reduction review;
- prior canonical metadata and receipt identities, preserved for audit.

**Execution gate:** call `validate_foundation_inputs(implementation, args)` before
any future candidate execution or public-query check using these artifacts. It
checks the bound official-domain contract and exact frozen validator identity,
then rejects out-of-domain inputs. Metadata retrieval alone neither executes a
candidate nor bypasses this requirement. 832's in-place values/root-alias policy
is explicitly local; child-row identity remains unspecified. Other local profiles
preserve inputs and reject mutable input/result aliases. 916 permits arbitrary
result order but not missing or duplicate words.

Finite 3,844-case checks across 126 isolated calls remain finite evidence, not universal
correctness or asymptotic proof. Historical malformed-domain failures, compatibility
probes and all previous population/threshold definitions remain untouched.
