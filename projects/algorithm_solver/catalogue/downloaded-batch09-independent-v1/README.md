# Batch nine independent qualification

This is an exposed-source audit of the exact 80 supplied solve functions in
`authored/downloaded-general40-v1`, not an independent-admission receipt or a
catalogue promotion. The immutable-input, fresh mutable return contract applies.
Original sources, protected Gamma payloads, descriptions, vectors, retrieval and
composition remain untouched. Root owns review and publication.

Cases derive from cached official definitions, independent small-state enumeration
and seeded cases, plus separately justified maximum-size analytic fixtures.
Expected values stay outside the child. Python and JavaScript agreement is never
an oracle. Public premium statements are unavailable for eleven identities:
1151, 1167, 1182, 1183, 1196, 1197, 1198, 1228, 1243, 1271 and 1272.
Their provisional observations cannot close qualification. 1271 receives decimal
string arguments, with no coercion to hide the original interface mismatch.

References enumerate swaps, all substrings, pair-merge trees, dice compositions,
Manhattan distances, feasible binary grids, Gregorian dates, subarrays and
subsequences, reachable swap permutations, gold path visited states, exact seat
choice probabilities, retained parentheses, word subsets, interval unit cells and
all candidate squares. Freedom predicates accept every valid binary cycle,
minimum parenthesis deletion and two-row reconstruction, plus unordered
transaction/queen results with multiplicity. Types, effects and mutable aliases
are checked independently. Before/after observation cannot establish absence of
transient writes: static review finds original 1219 modifies caller cells and
restores them; this separately blocks its immutable-input qualification.

Every original body in both languages was reviewed. 1163 compares every suffix
and has quadratic equal-character work; 1254 recursively visits up to 10,000
cells; 1219 mutates its input and explores all simple paths; 1271 expects a
numeric argument instead of the canonical decimal string. Original failures are
retained. Any repairs are new source identities with separate freezes and replay.

Only the existing Jupiter bubblewrap judge executes candidates, one interpreter
at a time for this task, with address-space 1 GiB, CPU 3 seconds and wall 8 seconds
per batch; stdout/stderr cap 16 MiB. Ordinary batches repeat their first call to
expose persistent-state dependence. Maximum fixtures run alone. Candidate argv,
source bytes, adapter, judge, limits, runtime binaries/libraries/stdlib, statement
pins, exact generated cases and batch plans freeze before execution. Inputs and
harness enter the sandbox; host expected results and statements do not.

`qualify.py freeze` creates the contract, `qualify.py run` retains identity and
per-batch starts/raw streams/results before verdicts, and `verify.py` reconstructs
all host expectations and replays retained raw results without executing sources.
Original official class/method wrappers are syntax-reviewed only and are not
execution-qualified by this solve-only run. No universal correctness or admission
claim follows from finite tests. The runtime side-effect observer covers final
state and returned aliases; static source inspection supplies the transient-write
gate. No protected source or held-out Gamma tests were read.
