The selected 50 pairs (100 language implementations) passed independent finite
qualification of the functional `solve` adapter. This is 96 original source
files plus four separate repaired variants. It is not 50 new active catalogue
pairs: source selection, catalogue promotion and official wrapper execution
remain separate.

The untouched originals passed 96/100 source gates. Both Prime Palindrome (866)
implementations exhausted the three-second CPU budget at legal `n=10000000`
(expected `100030001`). Both K Closest (973) implementations returned aliased
point rows, violating the local fresh-output service envelope. The official
point-output problem does not itself forbid those aliases. Original failures
and all raw streams remain retained.

The 866 variants enumerate odd-length palindromes in increasing order after
handling the prime 11 exception. The 973 variants copy each selected point row.
A distinct root reviewer approved the exact four source hashes before their
new freeze and execution. Original sources were not overwritten.

Both runs used 5,971 independent definition-derived case templates and 1,140
sequential sandbox batches. The repaired selection completed all 12,738 calls,
with 1,140 successful processes and zero failed source gates. Baseline dispatched
12,738 calls, completed 12,736 observations, and had two CPU-killed processes.
Both raw reports were independently regenerated/replayed on Jupiter and Mars
with matching receipts. Expected results never entered the candidate sandbox;
Python/JavaScript agreement was not an oracle.

`qualification.json` binds every source to its official definition, interface,
effects, source review, helper/test bytes, transport, runtime, resource limits,
raw summary, frozen run and replay. `evidence/` preserves reports, replay hashes,
execution metrics, archive hashes and executor receipts. The executor's
`testedCommit` is workspace context: the actual code identity is the exact
content-addressed source archive and freeze, including uncommitted helper bytes.

Raw source/statement/result archives are hash-checked on Mars and Jupiter under
`projects/algorithm_solver/runs/downloaded-batch07-independent-20261027/`.
Their locations and SHA-256 values are recorded in `qualification.json`.
After extracting an archive, raw evidence can be replayed without candidate
execution by importing `verify.verify(freeze_path, statement_directory,
result_directory)` and comparing its returned object with the retained
`replay.json`. The CLI writes a new replay with exclusive creation; use the
function to verify a directory that already contains its original replay.

No protected historical solution/test payloads were used. This is an exposed
cohort with finite tests and static source review, not held-out admission,
formal universal proof or official judge acceptance. All class wrappers remain
execution-unqualified. General service admission, active promotion, live
retrieval and composition were not changed by this assignment.
