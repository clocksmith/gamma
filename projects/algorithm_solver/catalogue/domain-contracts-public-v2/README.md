return semantics, official clause locations, and explicit unstated effect fields.
Its `<id>.cases.json` holds independently authored small synthetic inputs and
expected values: 39 cases total, not candidate-executed. Larger boundary plans
remain plans, not results. Expected values must stay outside candidate sandboxes.

The source pin hashes each exact retrieved web-tool response, not raw HTML.
Full source text is not redistributed. The authored summaries and references
remain reviewable; the digest does not turn a changing webpage into an immutable
publisher archive. Manifest hashes bind these JSON artifacts separately.

Important distinctions for independent review:

- 120 requests linear extra space as a follow-up, not an unconditional base
  requirement. No mandatory asymptotic bound is invented for this batch.
- 1514 uses real probabilities and explicitly allows absolute error at most
  `1e-5`. Rejecting nonfinite transport values is a proposed local policy.
- 988 needs a separately reviewed tree adapter. Its proposed recursive JSON
  representation is not an official API signature. Maximum-depth behavior needs
  a runtime-bound check, not merely a tiny-tree pass.
- Mathematical edits in 1005/1122 do not themselves specify caller-visible
  mutation or alias identity. All effect policies remain unadopted local proposals.
- String alphabets are stated explicitly where relevant; generic Unicode input
  is not silently admitted. Ordinary integer quantities in this batch fit exact
  JavaScript Number arithmetic; 1514 is the deliberate floating-point exception.
