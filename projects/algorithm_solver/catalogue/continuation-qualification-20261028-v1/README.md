# Fixed continuation qualification protocol

This prospective owner prepares the twenty explicitly assigned A/B identities
in `population.json`. It is not a general judge, source finder or permission
registry. Fixed assignment/manifest hashes, frontend IDs, slugs, public content
hashes and ordered APIs must all match. Existing six-anchor boundary policy runs
before every source/statement open and public-definition fetch. Protected or
unknown decisions stop that operation; a public URL does not override policy.
Anchored no-follow reads preserve the existing file boundary.

No candidate was executed while developing this tooling. Source-free controls
use synthetic observations and a mocked sandbox. Preparation does not qualify
anything. Linux freeze/run require the existing interpreters, sandbox, linked
libraries, Python standard library and the exact passing 37-check judge-preflight
log; there is no native macOS execution fallback or runtime installation path.
The preflight log and actual runtime hashes are bound in the new freeze.

## Private executor inputs

After reviewed source publication and an ordinary Git fetch, use the executor's
already-present original boundary descriptor and its independently pinned hash.
`prepare` refetches only the twenty fixed public GraphQL definitions into a new
private directory on that executor. Responses must match frontend ID, slug,
title, complete content hash, API hash and public availability. Local private
statement/case copies are not transferred. Full statement text never enters the
public source tree or sandbox.

```sh
python3 protocol.py prepare --gate ORIGINAL_GATE --gate-sha256 PIN \
  --statements NEW_PRIVATE_DEFINITION_DIRECTORY
python3 protocol.py review-template --gate ORIGINAL_GATE --gate-sha256 PIN \
  --review NEW_PRIVATE_REVIEW_TEMPLATE
```

The review template starts with every approval flag false. A reviewer must
actually inspect exact source, contract, definition, references, observer,
effects, numeric and mandatory complexity obligations before recording an
approval. Source/reference/observer/content/API hashes bind each review. An
absent, false or differently bound review cannot produce a qualified result.
A review grants no source-access authority and changes no catalogue slot.

```sh
python3 protocol.py freeze --gate ORIGINAL_GATE --gate-sha256 PIN \
  --statements PRIVATE_DEFINITION_DIRECTORY --preflight EXISTING_LINUX_LOG \
  --preflight-sha256 LOG_PIN --review REVIEWED_PRIVATE_RECORD \
  --freeze NEW_PRIVATE_FREEZE
python3 protocol.py run --gate ORIGINAL_GATE --gate-sha256 PIN \
  --statements PRIVATE_DEFINITION_DIRECTORY --freeze PRIVATE_FREEZE \
  --freeze-sha256 FREEZE_PIN --output NEW_PRIVATE_RUN_DIRECTORY
python3 protocol.py replay --gate EXISTING_LOCAL_GATE --gate-sha256 LOCAL_PIN \
  --statements PRIVATE_DEFINITION_DIRECTORY --freeze PRIVATE_FREEZE \
  --freeze-sha256 FREEZE_PIN --output PRIVATE_RUN_DIRECTORY
```

A separately authorized host replay may use a relocated existing gate descriptor
only when all six original trust anchors match; it reports the original and
relocated descriptor hashes separately. It does not pretend their bytes have
one hash. Replay regenerates every host expectation, exact input packet, batch
plan and verdict and checks raw stream hashes/counts and all reports. It never
executes a candidate. Moving any private evidence still needs its own authority.

## Frozen transport and unchanged resources

Python uses the existing easy16 observer. JavaScript uses the already versioned
direct CommonJS-function observer with the unchanged easy16 effect utilities.
No source rewriting, wrapper injection or object-to-function coercion occurs.
Official wrapper methods/classes remain unqualified. Only sources, trusted
observers and argument packets enter the sandbox; expected values stay on host.

Existing child limits stay unchanged: 1 GiB address space, three CPU seconds,
eight wall seconds, sixteen processes, 64 descriptors, 1 MiB child-file writes,
16 MiB output and Node 256 MiB old space, with the existing namespace isolation.
`RLIMIT_FSIZE` bounds child writes; it does not retroactively imply that earlier
host-side staging rejected large input files. This prospective protocol explicitly
bounds serialized host argument packets at 16 MiB. That is a separate input
envelope and never raises a child limit.

Small batches repeat their first call in the same interpreter. Large cases are
repeated only when both the exact packet bytes and projected result/effect stream
fit. Otherwise a small probe brackets the single large call in that interpreter.
If necessary, a single large call is retained with explicitly partial state
coverage and separate small repeated-call checks. Cases whose single observation
cannot fit remain named transport blockers; they are not silently omitted.
The freeze records every logical case, admitted indices, repeat policy, input
bytes and per-language projected output bytes. Outputs and actual byte counts
are retained before host judging, including process, protocol and value failures.

The A3627 maximal case requires one large observation rather than two: its
before/after arguments fit the unchanged output bound when bracketed by the
small probe. This projection is not an observed runtime or resource pass.

## Result semantics and limits of evidence

Both languages require exact typed results, unchanged arguments and no mutable
return/input alias edges. B3669 declares a list return: any positive integer
factor list of the correct length/product and independently recomputed optimal
range may pass. Equality with one chosen factor tuple is not required. Its
current independently bounded cases stay inside the reference's work budget.
No arbitrary supplied optimum is trusted.

Each program reports admitted-case passes separately from complete prepared
suite coverage, transport blockers and manual source-review gates. No admitted
cases means no pass. Any blocked case prevents complete-suite qualification.
Even a fully passing prepared suite is finite exposed-development evidence,
not formal full-domain correctness/resource proof, official judge acceptance,
wrapper acceptance, fresh generalization, canonical adoption or retrieval release.
Original exposure, source-blind design timing and reference-repair history remain
in their source-cohort records. This tooling does not repair historical evidence.
