# Q140 output-sensitive repair variants

These NEW Python/JavaScript variants address the root review's concrete complexity failure in the earlier Q140 sources. The old sources, semantics, design freeze and receipts remain untouched. Their declared output-sensitive bound is not retroactively validated by this repair. The observer interface remains the existing Q official route: Python original Solution.wordBreak and JavaScript the original exported wordBreak function. No solve adapter or observer-injected wrapper is added. Future qualification must select these new exact source hashes after independent review.

The live six-anchor source/statement gate authorized140 in both languages. The complete pinned public Word Break II response, content and actual Python/JavaScript templates were hash-verified before design/source creation. Official inputs are a lowercase string of length1..20 and a unique lowercase dictionary of1..1000 words, each length1..10. Full statement/template payloads and access-path receipts stay private; public files contain our own contract facts and exact hashes only. This verification binds the existing public snapshot and makes no claim of a fresh network fetch.

Let D be total dictionary characters, n the string length, W the maximum dictionary word length and A the sum of characters in all returned sentences, including spaces. Both variants implement deterministic fixed26-way tries, store matching edges as endpoint plus immutable dictionary-string references, compute suffix feasibility once, and REMOVE infeasible edges once before enumeration. There is no per-position sentence cache and no partial sentence-string materialization. If position0 cannot finish, they return a new empty list before enumeration, even if unreachable suffixes have exponentially many segmentations.

Time is O(D+n*W+A) under standard amortized array/list operations. The fixed alphabet costs26 slots per trie node, so construction is O(D). At most n*W character transitions and matching-edge records are examined; feasibility and pruning scan those edge records once. Each DFS edge leads to a complete answer. Every visited path prefix can therefore be charged to a word occurrence in at least one returned answer; total traversal work is at most the total answer word count, bounded by A because words are nonempty. Joining only complete leaf paths costs exactly the returned sentence lengths. Crucially, infeasible outgoing edges are pruned ONCE, so they are not rescanned for every feasible prefix.

Auxiliary space including returned output is O(D+n*W+n+A), equivalently O(D+n*W+A) because W>=1. Trie nodes, terminal references and matching edges are charged source structures. The active word-reference path and recursion stack are O(n); depth is at most n+1<=21 under the pinned domain. No recursion setting or execution cap changes. Inputs remain unchanged and output containers are fresh; immutable dictionary strings may be referenced internally. Unique dictionary words plus unique endpoint paths yield distinct sentences; result order is intentionally unrestricted.
