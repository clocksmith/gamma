Let N be distinct dictionary vertices plus beginWord (at most501), L the common word length, E the stored shortest-parent edge count, D the shortest ladder depth and K the sum of all returned path word counts. A, the total returned word-character count, equals L*K. The charged source builds a word-to-ID dictionary, BFS distance array, FIFO queue and shortest-parent DAG. It generates single-character substitutions and records every parent at exactly the next BFS distance. On finding the end depth, it finishes all remaining preceding-layer vertices before stopping, preserving all shortest parents.

Enumeration uses ONE mutable reverse-path array and ONE integer parent-cursor stack. It never copies a partial path on a DAG edge. Only at a complete beginWord leaf is a fresh answer path allocated in forward order. Parent distances strictly decrease, so every reverse prefix reaches beginWord and every expanded enumeration prefix belongs to a complete answer. Total enumeration pushes/pops/cursor work is bounded by the sum of answer path lengths; leaf copies cost exactly K. There is no extra multiplicative depth factor and no recursive call stack.

Expected time is O(26*N*L^2+K), equivalently within O(26*N*L^2+A), with standard expected hash-map operations and amortized array/list operations. Character substitution construction and hashing cost O(L) per candidate and are explicitly included. Dictionary construction costs O(N*L); BFS examines at most26*N*L substitutions. No candidate-string scratch is retained as a path cache. Parent edges use word IDs, while returned paths reference immutable original word strings.

Live auxiliary space including returned output is O(N+E+K+D+L): dictionary/vertex labels/queue/distances/parents cost O(N+E), the mutable path/cursor stacks cost O(D), candidate-word scratch costs O(L), and output paths cost O(K) references. Since the pinned L<=5, this is O(parentGraph+output+depth). If output is charged by serialized characters, O(N+E+A+D) is a conservative bound. Inputs remain unchanged; every result path container is fresh and outer result order is unrestricted with duplicates forbidden.
