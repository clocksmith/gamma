## Novelty Portfolio Contract

Do not let the target search collapse into an indefinite sequence of mixer,
weight, width, or reset-policy adjustments.  Classify every experiment as:

1. substrate tuning;
2. a new probability endpoint;
3. a new reversible representation;
4. a new coder or explicit event type.

After a terminal economics miss, a tuning lane receives one matched-trace
decision, not a native weight ladder.  A second native gate requires positive
evidence from a new endpoint, representation, or coder.  Keep at least three
orthogonal mechanisms in the cheap oracle or shadow stage while one candidate
is being integrated.

Speculative mechanisms use this funnel:

```text
decoder and inverse contract
  -> noncausal headroom plus matched control
  -> causal shadow or exact reversible transform
  -> counted disjoint-prefix implementation
  -> guarded native gate
  -> full official proof
```

An oracle may kill an expert universe but cannot promote a selector.  A failed
selector cannot retire an explicit-copy, grammar, graph, columnar, or delta
representation that creates different coded events.

`docs/wikiir_mdl.md` defines the primary orthogonal compiler program.  Its
first probes are parameterized Wiki tree grammar, prior-page prototype delta,
and a typed token Sequence Memoizer with Skip-CTS control.  WebGraph-style
typed list coding and nested columnar page blocks follow.  Article-order TSP
and generic residual-DAG search are demoted until these new representations
produce paying signal.

The endpoint428 lane is bounded by this contract: observation identity, one
matched larger-scope trace, then freeze one paying causal policy or retire the
family.

## Promotion Discipline

Do not promote an idea from this register because it is elegant. Promote only
when the receipt type matches the claim:

| Claim | Required receipt |
|---|---|
| Exact prefix candidate | Driver result JSON with roundtrip true. |
| Deterministic prefix candidate | Driver result JSON with determinism true or byte-equal replay. |
| Memory-safe candidate | RSS guard receipt under the selected guard. |
| SRSTC feature | Streaming retrieval shadow receipt with counted implementation bytes, deterministic table update hashes, held-out net savings, and conditional attribution for copy/typed/byte-prior controls when copy is enabled. |
| Residual/SSE feature | Shadow-coder receipt with counted implementation bytes. |
| Full target claim | Full `1G` official-accounting receipt with score at or below `109,500,000`. |

Evidence ladder for teacher and residual work:

| Level | Evidence | What it can decide |
|---:|---|---|
| 1 | Proxy or teacher forecast | Which experiment to run. |
| 2 | Shadow replay against the exact fx2 residual stream | Whether a signal transfers to the target substrate. |
| 3 | Constructive prefix receipt with decoder code counted | Same-scope candidate viability. |
| 4 | Multiple disjoint block receipts | Regression and transfer risk. |
| 5 | Full `enwik9` archive, roundtrip, determinism, memory, and official accounting | Score claim. |

Savant-style distillation boundary: offline teacher outputs, embeddings,
posterior traces, and oracle routing are discovery tools. A final Hutter
candidate may use only the distilled deterministic mechanism that the decoder
rebuilds from the already-decoded prefix, with every byte of code, table, and
configuration counted.
