# Autonomous Hutter Search Goal

## Objective

Discover, implement, falsify, refine, and certify a deterministic lossless
compressor for the exact one-billion-byte `enwik9` corpus whose complete
counted score is at most `108,000,000` bytes (`10.8000000%`). Count the archive,
decompressor, reconstructive source, tables, dictionaries, models, framing,
and every nonstandard runtime dependency.

Current boundary:

```text
verified full-1G score     unknown
best counted forecast     109,389,323
forecast evidence tier    constructive_prefix
remaining design debt       1,389,323
new score credit                     0
runtime eligibility        unresolved
```

External competitive claims are tracked separately from this source-bound
boundary. A 2026-08-02 `cmix-obias` artifact self-reports `108,492,825` counted
bytes but has no located committee verification and exceeds this project's
strict decimal-10GB RSS interpretation. If it is accepted unchanged, the next
one-percent prize ceiling becomes `107,407,896`, so `108,000,000` would cease
to be prize-winning even though it would be a smaller archive. Until that
external claim is authoritative, preserve `108,000,000` as the standing user
target and track the tighter value as a contingency. See
`docs/cmix_obias_external_candidate_audit.md`.

A forecast, proxy, teacher, oracle, shadow, prefix, or free-description
ceiling is never victory. Success requires a self-contained full-1G archive,
exact reconstruction, deterministic replay, complete package accounting, and
official CPU, memory, disk, and runtime eligibility.

## Operating policy

Operate as a proof-carrying adaptive research system. Maintain materially
different lineages when they expose different information or replace different
work:

- structural and exact-event compilation;
- decoder-built retrieval and graph memory;
- state-preserving bypass;
- compact replacement prediction;
- teacher-to-student distillation;
- arithmetic and finite-coder improvements;
- source/package reduction;
- measured runtime and memory replacement;
- newly discovered mechanisms absent from Gamma's mature endpoint.

Every actionable candidate begins with a frozen hypothesis, parent,
population, controls, accounting rule, transfer threshold, source ceiling,
memory/runtime boundary, and numeric kill condition. Use the smallest decisive
gate. Retire a neighborhood when a free ceiling is subscale, a matched control
explains the gain, selection or confirmation fails, package/framing costs erase
the gain, or submission resources make the implementation unusable. Do not
rescue-sweep a terminal miss.

Mine every result for reusable evidence: residual concentration, expensive
contexts, causal visibility, representation taxes, parent-state interactions,
runtime hotspots, and memory bottlenecks. Convert that evidence into a minimal
mechanism change rather than a cosmetic parameter variant. Preserve negative
knowledge in OMEGA exclusions and the research register so closed routes are
not rediscovered.

Never add gains from separate experiments when mechanisms change coding order,
event opportunities, predictor state, or arithmetic trajectories. Combine
such mechanisms only through a fresh exact joint replay with complete source
and framing accounting.

## Promotion ladder

1. Smoke, input identity, inversion, and arithmetic roundtrip.
2. Exact causal or paid-information ceiling with matched controls.
3. Actual terminated side and residual streams.
4. Chronological development, selection, and confirmation at 1M or 10M.
5. Distant/disjoint transfer using the frozen implementation.
6. Native deterministic integration and parent-state certificates.
7. Guarded exact 100M run with full program accounting.
8. Full-1G compression and decompression proof.

A 100M candidate must round-trip, reproduce its archive byte-for-byte, remain
inside the official resource limits, and retain enough package-adjusted gain to
forecast below `108,000,000` with a transfer cushion. That forecast authorizes
the full-1G proof; it is not the proof.

The preferred portfolio has multiple independent 100M-qualified descendants:
one representation-changing codec, one improved predictive substrate, and one
fresh joint composition. Continue until at least one CPU-eligible,
self-contained implementation reconstructs all one billion bytes and produces
a complete counted score at or below `108,000,000`. If an intervening verified
record makes that score insufficient for the minimum prize, tighten the final
admission boundary rather than declaring victory against a stale target.
