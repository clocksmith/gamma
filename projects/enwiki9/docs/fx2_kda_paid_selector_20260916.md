# Paid selection between retained memory trajectories

Candidate `fx2_kda_paid_selector250k_v1` uses deliberate creative lenses4/9:
branch compatibility and a paid regime selector. The earlier native KDA carry
lost3 archive bytes. Its validated conditional audit found a6917.5 ideal-bit
clairvoyant P/D opportunity, but only90.7 ideal bits under whole-piece hindsight.
Neither is a causal selector. This experiment resolves the explicitly held
bit-selection question without altering carry strength or native feedback.

The current final-bit learner is retired after a354-byte regression. Alternatives
considered in this discovery cycle: (1) the selected fixed paid selector;
(2) further exact weight packing, outside predictive adaptation, deferred because
the existing measured sign/magnitude package benefit is small and no new packing
dependency has been identified; (3) truth-driven memory gradients, deferred because
the necessary causal derivative and native state update have not been established.
These are my design/decoder/reviewer passes, not independent reviews.

## Frozen family

Use exposed raw `[0,250000)`, cold retained parent:151210 modeled WRT bytes.
Before each bit, context is `8*bit_position + 2*(P_count >> 14) + (D_count>P_count)`.
Each of64 contexts selects one of five interpolation weights `0,1/4,1/2,3/4,1`.
The emitted Q16 count is `((4-j)*P_count+j*D_count+2)//4`.
Counts remain1..65535; j=0 reproduces P. Exact tie rounding is upward.
The policy stores version1 and64 three-bit indices:25 bytes. Invalid indices5..7
are rejected. Even unused/identity entries pay. No outcome enters the context.

Fit on all exposed development data and transmit the selected table. Fit an
equally sized P/S table using the frozen shifted-carry trajectory, not a refittable
label permutation. No confirmation data, further bins, weights, retention values,
rate, population, or architecture search in this budget. Two independent fits
must produce byte-identical policies and receipts.

## Exact certificate and its limits

For each context all five alternatives see identical events and pay three bits.
Their ideal objective differs only by the product of integer truth counts.
Exhaustively maximize these products independently; stable ties select identity.
The product of these maxima attains the global maximum over5**64 policies.
Common Q**event_count cancels. Exact integer log-ratio floor/ceiling bounds give
the paid ideal gain after200 table bits and the aligned/control separation.
Floating logarithms are diagnostics only. This does not optimize a finite archive.

A positive paid lower bound and positive control-separation lower bound authorize
only finite-coder replay and native-state cost investigation. A nonpositive paid
upper bound closes this exact family on this population. Other cases are held.
No archive is produced in this gate and no full-corpus score is credited.

Both pre-truth count streams are supplied decoder dependencies, not free state.
The original FXCM consumes neural predictions and its learned state differs across
trajectories. Two native predictors cannot be assumed to share that state or meet
the memory limit. Count-stream bytes, dictionary, table, source and unknown native
closure must remain explicit. Even a positive diagnostic does not authorize native
integration before a feasible state/resource design exists.

Resource boundary: CPU2,2,000,000,000 memory bytes, zero swap,512,000,000 scratch
bytes,1500-second aggregate stop,600-second stop per repeated fit. This is a bounded
diagnostic with no new transformer run. Existing validated parent/conditional
reflections, traces, state witnesses, archives, source and population are hash-bound.
