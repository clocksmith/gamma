# Paid context instructions on the retained opening 10M

The 737-byte cold 1MB word-context improvement is valid, but its research parent
is not the codec behind the 109,389,323-byte forecast. It provides no measured
reduction of the 19,389,323-byte target debt. The next question concerns a
different mechanism and a matched strong-parent population.

The earlier two-pass MDL diagnostic obtained 336,970 ideal payload bytes with a
free model, while its best pruned paid table representation cost 2,813,101 bytes.
These configurations differ; their difference is not a measured packaging saving.
The retained exclusion explicitly leaves compact distribution prototypes open.
Generic copy programs, template grammars, parity reconstruction and one tested
large-language-model teacher have already failed their respective priced or
transfer screens. Repeating those descriptions is not a new mechanism.

The research portfolio considered these distinct directions before selection:

| Direction | Retained evidence and decision |
| --- | --- |
| Small retrieved residual programs or paid prompts | The [SRSTC exclusion](../operations/adaptive/exclusions/srstc_residual_program_candidate_universe_nonpaying_v1.json) records about 1.015 oracle bits per block before a four-bit selector. Park the unchanged candidate universe. |
| Decode anchors first, then predict missing material from both directions | The [parity token-fill diagnostic](../results/mobius2_janus_parity_token_fill_ceiling_qh0_v1/decision.json) has positive aggregate free-model headroom but negative selection and sealed partitions, plus a 4,723,671-byte compressed model. Park that realization. |
| Replace independent hindsight tables with paid shared instructions | The [MDL exclusion](../operations/adaptive/exclusions/parallel_mdl_model_description_v1.json) leaves compact prior-conditioned prototypes unsettled. Select one fixed representation for the bounded screen below. |
| Substitute a large language-model teacher | The [retained causal teacher screen](../results/mobius2_frontier_teacher_token_headroom_qh0_v1/decision.json) loses 9,741.9122 ideal bytes on its development population even with the model free. This checkpoint and alignment provide no launch case; other models remain untested. |

Candidate `paid_context_instruction_10m_q0_v1` tests a fixed order-six byte model.
Every context pays one flag bit; a selected instruction additionally pays eight
bits for a favored byte and four bits for its mixture coefficient. A shared
global distribution and all framing are stored in the actual model file.
Context keys follow from previously decoded bytes, so their spelling need not
be transmitted. The encoder can inspect the complete input because each selected
instruction is paid for and delivered before use by a hypothetical decoder.

The frozen experiment binds the complete retained 6,251,857-byte WRT store from
raw `[0, 10000000)`, including its five-byte header. This is exposed development
data, not the earlier cold confirmation sample. The matched retained parent costs
1,634,500 archive bytes plus 261,125 program bytes, or 1,895,625 total.

Two independent runs must reproduce both the numeric receipt and packed model
byte for byte. The model instructions are independently reconstructed; a rotated
favored-byte control measures whether the association matters. Synthetic checks
verify normalized probabilities, direct log loss and exhaustive discrete optima.

The result is a priced likelihood diagnostic, not a codec or certified universal
bound. Candidate code, WRT dependencies and finite entropy-coder termination are
optimistically excluded. An unfavorable result rejects this fixed representation
on this sample; a favorable result still needs a finite codec and complete costs.
Resource failures remain incomplete executions. No sample saving changes the
forecast or receives full-corpus credit.

The published experiment fixes CPU 2, 2,147,483,648 memory bytes, 67,108,864 scratch
bytes and a 360-second elapsed stop. It installs no model or dependency. Its
193,893.23-byte planning screen is the forecast debt divided by 100, not an
extrapolated result or a statistical guarantee.

See the [frozen experiment](../operations/adaptive/experiments/paid_context_instruction_10m_q0_v1.json)
for exact input hashes, controls, budgets and decision predicates.

## Closed result

Published source `209087008` ran as job `20260913T001644Z_a8f55fe2f3`.
Both complete replays and model instruction reconstruction passed. The closed
guard records 1,321,463,808 peak memory bytes and 1,654,784 peak scratch bytes;
all required discovery measurements are present and all violation flags are false.

There are 2,777,846 distinct contexts and 293,275 active instructions. Each active
instruction describes only one favored-byte adjustment. Even the resulting ideal
payload alone exceeds the counted parent.
The price of the model is therefore not the only problem: this replacement
discards predictive strength the existing codec already has.

The [terminal receipt](../operations/provenance/paid_context_instruction_terminal_20260912.json)
and [validated reflection](../operations/adaptive/reflections/20260913T001644Z_a8f55fe2f3.json)
reject this fixed representation on this exposed sample. Three terminal-index
ledger rows retain U/D/S likelihood diagnostics with archive and inverse claims
explicitly absent. This is a completed negative model-cost screen, not an observed
archive regression, resource failure or disproof of all instruction models.

A useful successor must establish shared, paid corrections to the strong
predictor's remaining errors, or retain its predictive strength in a replacement.
Changing the name to a prompt, quine or semantic instruction does not establish
that property. No such successor is claimed tested or launched here.

Full-corpus score remains unknown. The best counted forecast remains 109,389,323
bytes, 19,389,323 above the 90,000,000-byte (9.0000000%) target. Neither this screen
nor the separate cold 1MB gain changes that forecast.
