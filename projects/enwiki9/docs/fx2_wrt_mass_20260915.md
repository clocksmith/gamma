# Expert legal-mass correction of final coder odds

Previous progress is the closed native WRT omission experiment: P33429,D33423
bytes,source ZIP+1844,binary+4928. It proves native inversion and parent learning
preservation but does not pay its tested component cost. Its exact58..59-bit
information interval covers only the fixed omitted events, not ambiguous bits.
The native candidate remains held without inventing an archive-loss predicate.

This is one new probability family. It has no learned table, fitted strength,
window search, or model update. It is not a cheaper serialization of omissions.
Use the parent's existing205-way neural expert as an approximation to how legal
format support is distributed between the two still-possible bit branches.

Let c be the actual parent Q16 count for one. At the decoded byte prefix, C0,C1
are original neural masses; A0,A1 are those masses restricted to the source-proved
WRT legal byte set. For ambiguous legal branches, set

    a = c*A1*C0
    b = (65536-c)*A0*C1
    corrected = clamp_1_65535(round_half_up(65536*a/(a+b)))

Forced branches retain exact interval omission, with all parent learning events
preserved. If A0/C0=A1/C1, the integer count is exactly c. If the expert's binary
conditional equals the parent's, the unrounded expression is exactly Bayesian
conditioning on legal support. The actual parent and expert can disagree;
there is no general positive-gain theorem for this transfer.

Each retained binary16 expert value is converted exactly into integer units
2^-43 and clamped to8796093, the exact binary32 value1e-6f used by the native
parent. All entries must be finite in[0,1]; the summed row must lie in[1/2,2].
The common scale cancels. The correction numerator is below2^120 and fits an
unsigned128-bit integer. No logarithm or floating operation is needed for this
prospective decoding kernel. Log-loss summaries are explicitly diagnostic.

Source alignment: Predictor::TransformerByteUpdate feeds completed input i,
exports its post-update binary16 row, applies the binary32 floor, and sets the
byte mixer for i+1. On reset boundaries it exports the PPM fallback in the same
orientation. The retained P source, binary, full archive and repeated neural
rows must match their closed receipts. Coding byte0 uses no neural row because
the mode byte7 is forced. Coding byte i>0 reads only row i-1. The last retained
row predicts beyond the population and is never used by the coder.

One conditional gate uses exposed raw[0,250000),151210 WRT bytes. K computes
expert masses but retains the native omission archive33423 exactly. M uses the
fixed odds correction. S cyclically rotates the205 masses by one symbol before
computing both original and legal branch masses. No fitting can undo this
wrong-label control. K/M/S share grammar state, parent counts, row availability,
model capacity and elision schedule. M/S each pay a two-byte version/mode header;
K preserves the existing two-byte omission header. Original P33429 is retained
as a separately authenticated reference.

Six synthetic tests cover all15361 nonnegative half values through1, both zero
signs, all255 binary prefixes, exact Bayesian/null identities,5012 native128-bit
boundary/random vectors, previous-row-only access and nine independent
encode/decode/repeat processes without the source truth file during decoding.
The initial test import failed because the retained helper expects its sibling

not changed to repair the import.

This screening deliberately seeks target-bearing headroom: actual M archive
gain against P must be at least3000 bytes, and M must beat K and S strictly.
This is a prospective research spending threshold, not a full-corpus forecast
or mathematical lower bound on the gain required on every small population.
A positive smaller gain remains a scoped result but does not authorize native
integration. A valid archive/control loss rejects this fixed correction; no
strength/rotation/mask rescue. Any inverse, state, provenance or resource failure
is incomplete evidence. Native pricing follows only a pass; larger gates remain
unauthorized. No separate gains may be added.
