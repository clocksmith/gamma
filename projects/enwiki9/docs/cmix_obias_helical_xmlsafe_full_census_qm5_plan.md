# QM5 full-corpus XML-safe census

QM5 applies the frozen QM4 selection rule to the complete canonical enwiki9 and
the unchanged full raw far-history ledger. It does not run a compression backend.

The receipt records exact safe match counts and bytes across thirds and deciles,
the finite compressed copy ledger, empirical distance and length entropy, and a
conservative compressed charge for the complete QM4 transform/inverse source.
It calculates the direct eight-bit deletion ceiling against the 3,492,825-byte
`cmix-obias` research-parent debt plus a frozen 500,000-byte reserve.

The direct ceiling does not include actual parent surprisal or retained-stream
trajectory effects. A passing census only authorizes matched backend
adjudication; it earns no score credit and cannot establish the 105M target.
