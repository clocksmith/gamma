# Gamma enwiki9 Candidate Portfolio - 2026-07-25

## Purpose

This document records two project-new synthesis portfolios without treating
proposals as compression evidence or publication-level novelty claims. The
machine-readable companion is `docs/candidate_portfolio_20260725.json`.

Evidence rules:

```text
considered or parked proposal       -> zero score credit
truth-aware oracle                  -> zero score credit
shadow probability result           -> zero score credit until exact replay
exact prefix replay                 -> evidence only for measured scope
full win                            -> exact counted 1G score <= 108,000,000
```

The active hierarchy remains:

```text
engineering checkpoint              109,000,000
minimum prize-competitive gate      108,500,000
canonical design target             108,000,000
current forecast                    109,389,323
canonical design-target debt          1,389,323
```

A score mechanism should show roughly `1,500 B/M` in a truth-aware distant-
window feasibility oracle and approximately `2,100 B/M` in canonical 10M exact
replay after estimated source growth before native promotion. Runtime candidates
must replace measured work rather than run beside endpoint428.

## Required Controls

Every score candidate must report:

```text
literal control
current causal control
truth-aware oracle, when applicable
frozen causal shadow
exact finite-precision arithmetic replay
opening and distant page-complete holdout
source/package growth
peak state and runtime
largest block or page regression
```

Every replacement candidate must report:

```text
N0 = reduced predictor in original execution path
N1 = identical capacity with replacement mechanism
exact archive and roundtrip
controlled encode and decode timing
component-level cycle attribution
memory and package accounting
```

No portfolio component may inherit gains from another experiment. Registered
compositions must replay their complete subset lattice. A slice may lose alone
only when its removal from the full composition causes reproducible net loss on
development and sealed holdout after package and runtime accounting. Additivity
is never assumed. See `docs/winning_compositions_20260725.md`.
