`fx2_release_delivery_selection_20260915.json`. It neither promotes that package
nor alters the released predictor. The question is whether the existing
34-byte development saving occurs on a separately declared population.

independent decoding and re-encoding decoded raw data, for each arm. Every
rebuilt executable must match its released hash. Both preprocessors must match
the retained transformed bytes; P must reproduce its retained archive. Require

Use CPU 2, 9,999,998,976 bytes of memory, zero swap, 16GB logical scratch, and a
3,600-second aggregate stop. Build, preprocessing and codec phase stops are
