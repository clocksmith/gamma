This gate promotes the unchanged serialized 32/32 update schedule from its
exact 10,000-symbol source-native certification. A fresh canonical source-tar
build creates the parent archive; the same source tree is then patched and
rebuilt for the candidate. Both consume the first 65,536 symbols generated by

Promotion requires at least 3,000 actual archive bytes, exact raw-prefix
reconstruction, a valid serialized schedule header, complete source package
at most 1,300,000 bytes, and decimal-memory compliance. Any miss retires this
larger native promotion without split, optimizer, learning-rate, segment,
stream, vocabulary, or neighboring-scope sweeps.

The result has zero full-corpus score credit. A positive receipt only
authorizes the next larger exact source-native gate and a separate runtime
replacement/distillation decision.
