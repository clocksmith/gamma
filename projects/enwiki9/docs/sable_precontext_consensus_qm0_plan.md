# SABLE Preceding-Context Consensus QM0

Status: frozen deterministic impossibility ceiling; zero score credit.

## Question

Can the 32 bytes decoded immediately before a target identify a continuation
more than 60,000,000 transformed bytes back without transmitting a source,
distance, or length? This gate corrects the earlier far-history scanner: bytes
at the beginning of the target match cannot activate a predictor before those
bytes have themselves been coded.

## Frozen construction

The input is the receipt-bound 587,138,826-byte `transformed_ready.bin`,
SHA-256 `7826ff63dedd526c119dda08e6e044be8fa8f6e89a55f3d6b1f3447cdfc5c1ce`.
At positions whose preceding 32-byte rolling context has low six hash bits
zero, admit only exact collision-verified occurrences strictly more than
60,000,000 bytes old. A context state retains every admitted source through
their common-continuation LCP. The target contributes only the prefix that
both agrees across all candidates and equals the actual target continuation.
The chronological union is counted once.

The shifted-37 control uses the same activation, source ages, state capacity,
and target population while shifting the representative continuation by 37
bytes. Two complete scans and their canonical disjoint interval artifacts
must be byte-identical.

## Absolute gate

The donor debt, package allowance, and reserve total 4,056,825 bytes. Even a
perfect predictor cannot save more than eight bits per target byte. Therefore
fewer than 4,056,825 distinct correct consensus bytes is an unconditional
failure for this deterministic-consensus realization and no donor probability
trace is needed. Promotion additionally requires positive coverage in every
third and at least 100,000 bytes over the shifted-37 control.

A coverage pass authorizes only exact donor-surprise extraction on the frozen
intervals. It does not authorize a native expert.

## Memory boundary

Report exact key and state payload sizes, hash-bucket storage, guarded process
RSS, the donor's existing 672,375 KiB decimal-limit overage, and the minimum
donor memory deletion needed before adding the compact state. No additive
native implementation is eligible without a separately identified removal.

This ceiling does not rule out probabilistic gains when candidate
continuations disagree. It closes only deterministic preceding-context
consensus if negative.
