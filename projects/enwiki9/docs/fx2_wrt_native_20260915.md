# Native WRT elision and component pricing

The closed conditional comparison saved six archive bytes on opening raw
[0,250000): P33429, vocabulary-only33431, WRT33423. It included a two-byte
format header but required supplied parent counts. This successor removes that
runtime dependency, preserves the exact archive, and measures implementation cost.
It has no predicted full-corpus score or scale authority.

The earlier September8 WRT support deployment used a different50051-byte
profiling fixture and projected certain continuation counts to1/65535. It saved
two archive bytes and did not pay its added delivery ZIP. The present mechanism
actually omits forced arithmetic events, accounts for dictionary cardinality,
case controls and escapes, and uses the separately measured250KB population.
It does not inherit the earlier savings or reopen an unchanged packaging sweep.

The native state machine implements the frozen Python grammar. The dictionary
count is rebuilt from the required dictionary with its original file position
restored. Vocabulary comes from the existing paid archive. Every bit calls the
parent Predict and Perceive exactly once; only arithmetic interval advancement
is omitted. Forced encoder truths must match the pre-truth grammar. Decoder
truths are derived from that same grammar. Version/mode bytes1,1 precede GFV1.
The supported boundary remains one static-vocabulary TEXT body with dictionary.

Five synthetic tests compare every post-bit state across all44880 dictionary
codes, boundary dictionaries, case/escape strings and restricted vocabularies.
A compiled copy of the actual patched coder runs against a deterministic stub
predictor, verifies every prediction/update call and the final predictor state,
and matches independent Python arithmetic archives. An interrupted first test
attempt copied the entire ctypes output on each comparison; the corrected test
reads it once. Codec source was not changed by that harness correction.

One frozen native gate uses CPU2,9999998976 bytes memory,zero swap,
24000000000 logical scratch bytes and1800 seconds aggregate stop. Phase limits
are360 seconds/build,30/clean,180/codec. Pin the lab controller toCPU2 before
spawning the guard. Three binaries are built serially: bookkeeping with observer,
elision with observer, then released elision without observer. The release is
rebuilt after make clean with the observation header physically removed. Nine
encode/decode/repeat operations and seven build/clean operations are required.

K must reproduce P33429 and its retained counts exactly. D and released D must
reproduce the conditional33423-byte archive. Both observed variants must match
all1209680 native counts and post-bit WRT states; independent decoder/repeat
traces must be identical. Released decoding uses only its archive, existing
model/dictionary and executable. Full parent tensor/optimizer state is not
serialized; per-event counts, call schedule and exact inverse are the declared
state evidence. No trace file is a runtime requirement of the release.
