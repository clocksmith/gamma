# enwiki9 Constructive Mathematics Index

Updated: 2026-07-27

This index separates mathematical completion from native transfer and Hutter
score credit. An exact theorem can authorize a construction or an accounting
inheritance. It cannot create predictive gain or resource eligibility.

## Status vocabulary

- `MATH_COMPLETE`: every fixed theorem clause has a constructive proof.
- `INSTANTIATED`: a finite candidate or verifier implements the construction.
- `NATIVE_QUEUED`: an exact native gate is durably queued.
- `NATIVE_VERIFIED`: roundtrip, determinism, and the stated resource gate pass.
- `SCORE_VERIFIED`: a complete counted score receipt supports the stated delta.
- `OFFICIAL_WIN`: exact full-1G total is at most `108000000` and all official
  resource rules pass.

Only `OFFICIAL_WIN` completes the project objective.
