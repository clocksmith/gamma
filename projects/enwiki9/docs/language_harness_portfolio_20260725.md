## Evidence boundary

This portfolio records hypotheses, not compression results. No proposal receives score credit until a causal, exact, deterministic arithmetic-code or native-codec receipt survives its declared disjoint gate with source, memory, runtime, and framing costs counted.

The motivating literature establishes that document organization can be represented through entity transitions, event chains, discourse-relation graphs, dependency relations, and shared latent views. It does not establish that these representations improve enwiki9 compression. Raw bytes and WRT are deterministic views of the same source; pseudo-languages and parses contain no free information. Any gain must come from parameter sharing, better causal state, or cheaper execution.

Corrected Gamma boundary:

- SRSTC showed weak-substrate gain but no useful FX2 target transfer.
- CMEM was exact and causal but lost one held-out byte and is retired.
- ARIADNE-0 is terminal, not untested: ordering saved 118 bytes, while complete framing lost 9,069 bytes at 1M.
- General MOIRAI WRT inference is retired; the constrained XML residual variant remains parked.
- XML21's last recorded 10M encode result was 872 archive bytes worse while mature execution improved by about 26.76 seconds; live certification status must come from current receipts, not this portfolio.

## Authorized bounded probes

### D02: `twinstream_raw_wrt_dual_reconstruction_v1`

Controls:

```text
P0  bounded WRT predictor
P1  P0 + causal raw-history features
P2  P0 + shared raw/WRT state
P3  P2 + completed-event reverse reconstruction training
PX  P0 + matched-capacity non-shared raw features
```

Contract:

- Encode the unchanged original WRT trajectory with fresh causal replay.
- Align state updates to indivisible WRT emission groups.
- Reveal raw expansion only after the group that determines it is completely decoded.
- Train reverse reconstruction only on completed past events.
- Compare P2 and P3 against PX, not only P0, to isolate sharing from added capacity.
- Freeze development selection before page-disjoint holdout and offset-500M transfer.

Kill when the selected model is non-positive on exact holdout, fails offset transfer, or fails source-adjusted and runtime-adjusted economics.

### D10: `autopsy_self_harness_residual_miner_v1`

Input fields:

```text
true bit and loss
base and component probabilities
WRT event and completed raw expansion
XML/Wiki/page/section state
model activation and update timing
runtime attribution
candidate and population provenance
```

The proposal language is deliberately small: add or remove one context coordinate, alter one update boundary, split or merge one regime, remove one destructive feature, add one exact macro, replace one container, or change one frozen blend. Every child enters the existing adaptive proposal, mutation, run-ledger, and terminal-receipt workflow. Rejections become searchable negative evidence.

### D07: `qud_heading_answer_state_v1`

Ablations:

```text
Q0  baseline
Q1  exact completed heading hash
Q2  online MDL-merged heading family
Q3  heading family + page-local entity recurrence
```

The heading state opens only after its exact WRT events are decoded and closes at the next heading or page boundary. No heading label, role, or schema is transmitted. Kill on non-positive exact holdout or if gain is confined to references, category tails, or the opening population.

### D06: `chronicle_entity_event_oracle_v1`

Use deterministic completed-sentence entity recurrence, grammatical-role approximations, tense markers, and section position. Measure counterfactual exact loss by page family before implementation. A valid signal must be positive for biography/history holdouts, survive offset transfer, and cover enough events to repay parser and routing bytes.

## Two-plane architecture L01

Name: `babelshell_frozen_discovery_plane_v1`

```text
offline improvement plane
    D10 AUTOPSY residual mining
    D09 DARWIN lineage archive
    existing adaptive workflow and exact gates

frozen submission plane
    unchanged exact arithmetic-coding path
    independently positive D02 TWINSTREAM slice
    independently positive D07 QUD slice
    independently positive XML21 slice, if certified
```

Rules:

- No LLM, mutation search, benchmark replay, or code generation runs inside the submitted compressor.
- The final source is frozen, deterministic, and counted normally.
- Components enter a composition only after standalone causal receipts.
- Test the complete subset lattice: baseline, A, B, C, AB, AC, BC, ABC.
- A standalone loser may survive only when a frozen combination shows reproducible positive marginal interaction on development and sealed holdout.
- Existing `ADAPTIVE_WORKFLOW.md` remains the only operational queue and lineage system.
