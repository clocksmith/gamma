# Fixed KDA memory carryover

Candidate `fx2_kda_carry_opening250k_v1`, owner `root_kda_carry`, tests whether
native FX2 loses useful information when it clears recurrent memory at existing
article/piece boundaries. These resets match training; they are not a bug.
The [frozen contract](../operations/adaptive/experiments/fx2_kda_carry_opening250k_v1.json)
allows one configuration on the already exposed raw interval `[0,250000)`.
The cold `[819000000,820000000)` previous-word confirmation remains unchanged.

This selects the memory and state-transfer discovery lenses after the narrow
abbreviation study found little residual opportunity. The apparent double FXCM
update was already explained by two distinct experts, and the closing-name
opportunity study already exhausted its fixed integration budget. Neither is
revived. The newer FX2 parent has a retained 33,429-byte archive here; the older
Gamma forecast lineage has a 44,958-byte archive under its different frontend.
That cross-lineage observation is not the controlled comparison in this gate.

P retains the original zero reset. K computes then discards D's carry before
resetting. D preserves exactly 1/16 of each of nine KDA matrices. S rotates each
64-column value row by one before the same scaling. This permutation preserves
the retained value multiset and norm before the resulting trajectories diverge.
All arms clear convolution history and clocks and invalidate attention caches
at the original boundaries. They retain the original model, dictionary,
pretraining, frontend, omitted last-of-piece token, and all other native updates.

Each arm independently encodes, decodes and reencodes the decoded bytes.
Require exact inversion and byte-identical repeats, `A_P=A_K` byte for byte,
and P parity with the retained original archive and every coder trace record.
At every reset, compare all authoritative KDA matrices, convolution rings and
clocks, plus transformer position and RoPE offset. Old KV values are unavailable
when position is zero; scratch overwritten before reading and audit bookkeeping
are excluded. Other native components retain deterministic unchanged updates on
the same decoded bits and verified probabilities. This is not a serialization
of every native model allocation, nor a cross-architecture qualification.
