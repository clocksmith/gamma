## Frozen discovery universe

Parse non-overlapping outer MediaWiki templates with the already recorded
`wikiir_template_grammar_v1` ordered-hole parser. A template is represented as
alternating fixed segments and value holes:

```text
fixed_0, hole_0, fixed_1, ..., hole_n, fixed_n+1
```

Every boundary must coincide with a complete WRT emission-group boundary.
Map each fixed raw segment and hole to exact WRT byte intervals. Group
occurrences only when their tuple of exact WRT fixed segments is identical.
Raw-only skeleton equality receives no credit.

Complete chronological pages are divided once:

```text
development          first 60 percent
selection            next 20 percent
sealed_confirmation  final 20 percent
```

A rule key must appear at least twice in development. Rule definitions and
their order are selected from development only. For a frozen selected rule,
an occurrence is invoked when its displaced parent integer-qbit cost exceeds
its canonical invocation bytes. This literal fallback algorithm is fixed
before aggregate selection and confirmation signs are read.

Do not sweep occurrence count, nesting, hole count, rule count, page family,
integer code, or rule-definition compression.

## Finite rule and invocation stream

The control stream uses little-endian u32 counts and canonical ULEB128:

```text
u32 rule_count
repeat rules:
    uleb segment_count
    repeat segments:
        uleb segment_length
        segment WRT bytes
u32 invocation_count
repeat invocations in target order:
    uleb absolute_target_wrt_start
    uleb rule_id
    repeat rule holes:
        uleb literal_hole_wrt_length
```

The decoder infers literal gaps from the absolute target starts and the known
WRT total length. `GEN_RULE` writes transmitted fixed segments into their exact
positions. Holes and uncovered bytes come from the literal arithmetic stream.
Every output byte therefore occupies its original parent trace position.

## Controls and accounting

- E0: exact receipt-bound parent replay.
- U0: exact optimistic payload ceiling. Generate every occurrence of every
  rule key that repeated at least twice in development, but charge no rule or
  invocation bytes. This is an oracle only.
- S1: actual paid surface grammar with rule definitions, invocations, archive
  frame, terminated residual arithmetic payload, and measured source.
- SL: the identical S1 control stream and frame, but force every byte literal.
  This isolates generated-span value from command-selection freedom.

The actual archive has one mode byte, exact lengths, the finite control stream,
and a terminated 32-bit range-coded literal payload. S1 and SL must both
decode. A second construction of each archive must be byte-identical.

Source accounting is reproducible gzip-9 size of the candidate decoder, gate,
and the reused ordered-template discovery parser. Source is amortized once at
1G. The discovery parser charge is conservative because the final decoder
does not need to reproduce encoder search.
