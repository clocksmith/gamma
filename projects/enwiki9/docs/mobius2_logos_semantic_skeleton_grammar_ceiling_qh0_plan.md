## Question

The paid semantic sentence edit-bypass found no profitable exact-fragment
program among 172,554 retrieved pairs.  That rejects one source reference plus
explicit COPY commands; it does not establish that semantically related
sentences lack a shared parameterized skeleton whose rule definition and
invocation costs could be amortized across many uses.

QH0 asks the missing upper-bound question:

> If each target sentence may receive its best earlier semantic prototype and
> its exact matching WRT emission groups for free, how much actual
> JANUS-plus-quotient arithmetic payload can those groups displace, and is the
> gain specific to semantic retrieval?

This is an intentionally optimistic, zero-description-cost grammar ceiling.
It is not a constructive codec and receives no score or forecast credit.

## Free skeleton construction

Represent each eligible sentence as its exact sequence of WRT emission-group
byte strings.  For each target/candidate pair, run Python's deterministic
`difflib.SequenceMatcher` with `autojunk=False`.  Every nonempty matching block
becomes a skeleton fragment.  Adjacent blocks are merged only when both target
and source byte intervals are contiguous.

Each fragment copies exact WRT bytes from a strictly earlier source sentence.
The best candidate for one target maximizes the rounded-Q256 joint parent
codelength of its generated target intervals; ties choose the lower source
sentence index.  Target sentences are already nonoverlapping.

At QH0 the following are supplied out of band and charged zero bytes:

```text
prototype identity
matching-block schedule
rule definition
rule invocation
source and implementation
```

The following remain exact and paid:

```text
32-byte candidate frame
actually terminated residual arithmetic payload
all literal WRT truth bits
```

The decoder must use the supplied plan to copy each skeleton fragment from
already reconstructed WRT, decode every remaining bit on its original joint
P1 row, and reproduce the complete prefix.  The reconstructed prefix is then
inserted into the receipt-bound full WRT store for the official 10M inverse.
