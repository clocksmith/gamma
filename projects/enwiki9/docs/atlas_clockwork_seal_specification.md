# Private Atlas-Clockwork Application Seal

Classification: `ORGANIZER ONLY`
Seal version: `ACS-MATH-SEAL-2`

## 1. Purpose

This document is not part of the mathematical examination and must not be sent
to solvers. It defines a private, precommitted reduction from each independent
public theorem to a hidden finite application.

The public solver supplies only a mathematical manuscript. The organizer is
responsible for proving, before publication, that every rubric-complete solution
to every published route transfers through a frozen canonical application map
and satisfies the hidden target, exactness, and resource bounds.

A route for which that universal implication has not been proved must be
removed before the examination is published.

## 2. Frozen private commitments

Before publishing the examination, freeze and hash:

1. The public problem-set and private rubric versions.
2. The hidden input identity.
3. The hidden baseline or teacher identity.
4. A quantitative hypothesis-and-margin certificate for each route.
5. A total canonical application map for each route.
6. Every fixed-cost and variable-cost accounting rule.
7. Exact reversibility and determinism rules.
8. Exact runtime and memory rules.
9. The application verifier.
10. The transfer-verification procedure.
11. A proof of the universal transfer implication in Section 9 for each route.

The application map must resolve nonunique mathematical witnesses by a frozen
rule, normally lexicographic minimization under a canonical serialization. It
may not be changed after seeing a submitted solution.

Publication may expose only the commitment hash and timestamp. Private contents
remain sealed until disclosure is appropriate.

## 3. Route A private reduction

### 3.1 Interpretation

Map the hidden finite application into Problem A:

- Rows are paid-information blocks.
- Columns are finite explanations or prompts.
- Each gain is an exact jointly replayed gain before selector cost.
- Prefix lengths are exact paid selector costs.
- Description prices are exact surviving representation costs.

### 3.2 Prepublication certificate

Prove that every gain is generated by legal causal predictions and every
selected explanation is available before first use. Prove quantitatively that
the fixed A2 prefix gap, A4 perturbation allowance, all description prices, and
all hidden costs still leave the committed target margin.

### 3.3 Canonical application

From any `COMPLETE` solution, instantiate the lexicographically first optimal
assignment and the lexicographically first legal prefix representation allowed
by the proved theorems. Exact combined replay verifies the precommitted result;
it does not decide after the fact whether the route was sufficiently strong.

## 4. Route B private reduction

### 4.1 Interpretation

Map the hidden causal context system to Problem B:

- Finite histories become \(H\).
- Decoder-visible events become \(A\).
- Predictive signatures become colors.
- Causal updates become \(T\).
- Continuation geometry becomes the labeled quotient graph.

### 4.2 Prepublication certificate

Prove totality, causal availability of every color, and every public hypothesis.
Fix \(L\) and prove quantitatively that either the canonical quotient geometry
or the depth-\(L\) unfolding meets the hidden target and resource limits under
the public theorem's exact size and interval bounds.

### 4.3 Canonical application

From any `COMPLETE` solution, construct the uniquely defined behavioral
quotient. Where an order or witness is nonunique, select the lexicographically
first canonical serialization. Instantiate only the frozen predictor and
certificate committed before publication.

## 5. Route C private reduction

### 5.1 Interpretation

Map the hidden recurrence to Problem C:

- Selective symbols become \(\mathcal A\).
- Teacher transitions become \(A_a,b_a\).
- Teacher outputs become \(c,\gamma_a\).
- The Euclidean contraction and state bound become certified constants.

### 5.2 Prepublication certificate

Prove exact rational or outward-rounded values for \(\rho<1\), \(S\), every
matrix and bias error, output norm, sequence length, and cumulative loss
allowance. Fix a dyadic precision and factorization. Prove that the public C1-C4
inequalities leave enough hidden target margin and satisfy the resource limits.
A noncontractive hidden recurrence may not be bound to Route C.

### 5.3 Canonical application

From any `COMPLETE` solution, instantiate the committed nearest-dyadic rounding,
factor order, and precision. Exact joint coding verifies the frozen implication.
The organizer may not tune precision or factors after receiving the proof.

## 6. Route D private reduction

### 6.1 Interpretation

Map hidden constrained blocks to Problem D:

- Each residual becomes a vector in \(\mathbb F_2^n\).
- A causal structural prototype defines the residual set.
- A deterministic score defines the energy order.
- Linear checks become \(H_k\).
- Actual bounded reconstruction defines the candidate list.

### 6.2 Prepublication certificate

Prove prototype availability, exact residual mapping, deterministic energy,
finite parity semantics, and bounded candidate enumeration. Prove that the

with sufficient counted margin, runtime, and memory.

### 6.3 Canonical application

From any `COMPLETE` solution, choose the lexicographically first successful
matrix, extend it by the frozen basis order, and emit the canonical
bounded-search certificate. Exact reconstruction verifies the already-proved
implication.

## 7. Independence

Each route has a distinct hypothesis certificate and application map. No route
may use another route's theorem, proof, parameter, measured gain, or
implementation. Private acceptance is

\[
\operatorname{TRANSFER}_A\lor
\operatorname{TRANSFER}_B\lor
\operatorname{TRANSFER}_C\lor
\operatorname{TRANSFER}_D.
\]

For this sealed examination, a `COMPLETE` solution to any published route must
transfer. A later target or resource failure means the private Seal or organizer
implementation was invalid; it may not be attributed to the solver.

## 8. Exact application verification

For every transfer, the organizer produces:

- Bound input and artifact hashes.
- Complete representation and package accounting.
- Exact encode/decode roundtrip and deterministic second artifact.
- Exact joint arithmetic or reconstruction receipt.
- Peak-memory and encode/decode timing receipts.
- Source-to-theorem and theorem-to-artifact mappings.
- Final target decision.

Forecasts, proxy loss, oracle gain, asymptotic savings, and separately added
component gains do not establish transfer.

## 9. Universal private transfer theorem

For each published route \(i\), let:

- \(S_i\) range over every public solution graded `COMPLETE`.
- \(H_i\) be the frozen quantitative hypothesis-and-margin proof.
- \(\Psi_i\) be the frozen total canonical application map.
- \(V_i\) be the exact frozen verifier.

Before publication, prove

\[
\forall S_i,\qquad
\operatorname{COMPLETE}_i(S_i)\land H_i
\Longrightarrow
V_i(\Psi_i(S_i))=\operatorname{PASS}.
\]

The proof must include target and resource sufficiency, not merely mathematical
applicability. Without this implication and all committed objects, Route \(i\)
must not appear in the public examination.
