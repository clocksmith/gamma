## Role

WIKI-JOINT is not a fourth information source. It is the exact composition
contract for paying decoder-built event sources such as:

- WIKIBACK prior incoming-anchor contexts;
- WIKISECTION prior same-heading section bodies;
- WIKIFORWARD earlier decoded destination-page lexicons;
- a later WIKIGRAPH target-identity source only if its independent paid gate

At an eligible exact WRT-event boundary, each active source produces a bounded
prefix-causal snapshot. The codec forms one canonical union over exact encoded
WRT event byte strings, merges duplicate identities, aggregates only
pre-truth weights, and emits one finite `HIT + rank` or `ESCAPE`. A hit
reconstructs the exact encoded event; an escape consumes the event from the
parent arithmetic payload.

This joint replay is mandatory because isolated savings overlap and because
side coding changes arithmetic termination. Never add isolated WIKI gains.

## Causal and decoding contract

Every source record is published only at its frozen completed boundary. The
union, activation, capacity, duplicate handling, weights, ties, eviction, and
memory cap are deterministic functions of the decoded prefix and are frozen
before current truth.

Candidate identity is the exact encoded WRT event, not a decoded lexeme or
semantic label. The event grammar and framed finite side/residual streams must
give one unique next event at every position and reconstruct both complete WRT
and raw corpus bytes.


After every hit event, quiesce deferred work and compare:

- canonical logical parent predictor-state hash;

Exclude only arithmetic-coder interval/output state, which must differ when
truth bits are bypassed. A precomputed P1 trace proves trace accounting, not
native state equality.
