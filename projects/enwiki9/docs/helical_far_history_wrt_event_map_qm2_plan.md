# HELICAL Full-WRT Event Compatibility QM2

## Question

The frozen raw far-history population is separated by at least 100,000,000 raw
bytes, but Endpoint428 operates on the WRT stream and directly retains
100,000,000 modeled bytes. Which full-span C1 matches begin and end on exact WRT
event boundaries, have byte-identical encoded source and target programs, and
remain beyond the applicable modeled-stream history floor?

## Frozen inputs

The ordinary preprocessing-only FX2 binary reproduces the preserved canonical
10M store hash exactly. The same binary and dictionary materialize the full-1G
647,798,597-byte store with SHA-256
`fe6ab5b96ad7bf2b6f7bd9f7cd3b3212ffc7320ae290e098f68e97b53295ceb9`.
QM2 consumes QM0's fixed C1 stream and does not regenerate matches or sources.

The mapper streams every WRT event, reconstructs and compares every raw output
byte to canonical enwik9, and records encoded boundaries only after complete
output-producing events. A raw match survives only when all four source/target
endpoints are boundaries and its encoded source and target WRT spans are
byte-identical. Separate arms then enforce 100M and 60M WRT-byte distance floors.

## Paid representation

For each surviving arm, target gaps, address modes, full openings, signed
shifts, and WRT span lengths are serialized as deterministic columns and
compressed separately with finite LZMA streams. Framing and the complete source
package are counted. The Endpoint arm is priced at the current archive-average
rate per WRT stream byte only as a zero-credit ceiling.

## Gate

Both full mappings and every command column must be byte-identical. The full WRT
inverse and every selected encoded span must be exact. Endpoint-compatible
coverage must remain positive in every chronological third, and the average-rate
gross proxy must exceed commands, source, and the 4,389,323-byte debt before an
optional reserve. Only a pass authorizes a full Endpoint428 P1 observer. The
60M arm cannot inherit `cmix-obias` pricing because that parent uses a different
modeled stream.
