## Supporting mathematics already separated

`ACS-MATH-SEAL-2` contains four independent pencil-and-paper families:

| Family | Proved capability | Missing compressor antecedent |
|---|---|---|
| Paid-information selection | Optimizes a supplied finite gain matrix after selector, prefix, and description costs | A causal explanation family with target-scale joint gain |
| Predictive quotient and Wheeler geometry | Minimizes and indexes a supplied behaviorally useful finite state system | A decoder-visible state coloring with target-scale future information |
| Integer recurrence shadowing | Transfers a supplied contractive rational teacher into deterministic dyadic arithmetic with explicit loss bounds | An independently under-target teacher with contraction, state, package, and resource slack |
| Energy-ordered parity reconstruction | Separates and reconstructs residuals once the true residual has low searchable energy rank | A causal prototype, low-rank residual distribution, cheap enumerator, and paying syndrome ledger |

These theorems organize, compile, or reconstruct information that has already
been supplied. They do not create that information. `ACS-MATH-SEAL-2` remains
`UNBOUND`; no solver distribution is authorized and all solutions receive zero
compression credit.

The accepted mathematical scope is narrower and explicit. Paid-information
selection supplies the exact empirical optimizer, an integer prefix
construction, description-priced profitability, and the sharp finite
perturbation bound once a gain matrix exists. Predictive quotienting supplies
behavioral minimality, finite distinguishing certificates, Wheeler interval
geometry, and finite unfolding once a useful coloring exists. Integer
shadowing supplies contractive recurrence error, logistic-loss transfer,
rational Householder realization, and precision bounds once a sufficiently
strong teacher exists; its sharpness statement is exact for admissible rational
contractions and supremal for arbitrary real contractions. Parity
reconstruction supplies kernel separation and canonical first-hit recovery
once true residuals already have low searchable energy rank; its corrected
difference-set condition is `ker(H) intersect (B - B) subseteq {0}`. None of
these conclusions proves its missing empirical antecedent.

The later `ACS-PROVER-LIBRARY-1` similarly separates exact bounded-treewidth
candidate selection, ambiguity-DAG correction coding, weighted-transformation
recomposition, and abstract tree-memory scheduling. Those results improve the
research verifier. They do not prove that the finite candidate family contains
a competitive compressor. The first compression-derived transformation-monoid
pilot is the controlling example: its theorem and exact transfer worked while
the compression hypothesis lost eight holdout bytes.

The prover library therefore guarantees, respectively, an exact optimum inside
a supplied factorized candidate family, canonical rank/unrank and worst-case
correction bits inside a supplied ambiguity DAG, exact finite-state recomposed
cost for supplied local replacements, and minimum abstract peak memory under
its declared no-recomputation schedule. It supplies proof-carrying engineering,
not new prediction.

### 2. Causal realization

Make every decision a function only of decoded bytes, decoder-rebuilt state,
fixed counted code, and already paid transmitted bits. Future lengths,
encoder-only neighbors, hidden teacher state, external embeddings, and
untransmitted labels are forbidden.

Current status: this is where many free ceilings disappear. WIKI retrieval
plans therefore bind publication boundaries, source-key inequalities, duplicate
handling, prefix novelty, and capacity-matched causal controls before coding.

### 3. Compact compilation

decoder-built table, finite residual program, reversible event channel, or

and framing amortization.

Current status: no new target-scale mechanism has cleared this obligation.

### 4. Exact coding and inversion

Current status: this is a project strength. Exact range-coder, inverse, hash,

## Admission rule for a mathematical competition

A new solver competition is justified only when the organizer has already
frozen all non-mathematical antecedents:

1. Exact public specification and hash.
2. Hidden finite enwiki9 instance bound to one route.
3. Proved map from the requested theorem to an executable witness.
4. Canonical ordering and tie-breaking.
5. Decidable verifier with exact expected outputs.
6. Complete source, archive, framing, runtime, and memory accounting.
7. A proof that every complete accepted solution makes the hidden verifier
   pass the target-bearing threshold.

Missing data, implementation, teacher strength, benchmark results, package
bytes, runtime measurements, or full-corpus receipts are organizer obligations.
They must not be restated as open mathematics. If a theorem would merely help
search a family whose empirical headroom is unknown, the problem is not ready
for distribution.

This is the required precommitted transfer binding: before distribution, the
organizer must be able to prove that every accepted mathematical witness maps
through the frozen executable construction to a verifier result that clears a
named target-bearing threshold. "May help find a compressor" is not a transfer
binding.
