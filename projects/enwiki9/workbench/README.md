# Research workbench

Use [AGENTS.md](../AGENTS.md) for rules and permissions and
[ADAPTIVE_WORKFLOW.md](../ADAPTIVE_WORKFLOW.md) for all commands. Run them from
`gamma/projects/enwiki9/`. [PROMPTS.md](PROMPTS.md) supplies copyable task wording.

When the user says “go”, inspect current ownership and evidence with the manual's
[entry commands](../ADAPTIVE_WORKFLOW.md#start-and-find-records), then complete the
next justified action. A held gate can coexist with independent research.

| Task | Follow this part of the command manual |
| --- | --- |
| Find prior algorithms, failures, mixes, or tools | [Start and find records](../ADAPTIVE_WORKFLOW.md#start-and-find-records) |
| Research and choose a mechanism | [Discover and propose](../ADAPTIVE_WORKFLOW.md#discover-and-propose-algorithms) |
| Implement or change one mechanism | [Create](../ADAPTIVE_WORKFLOW.md#create) and [mutate](../ADAPTIVE_WORKFLOW.md#mutate) |
| Benchmark an exact codec | [Queue](../ADAPTIVE_WORKFLOW.md#queue) and [run](../ADAPTIVE_WORKFLOW.md#run) |
| Run a simulation, proxy, or diagnostic | [Queue a tool](../ADAPTIVE_WORKFLOW.md#queue) |
| Review results and preserve failures | [Record the discovery boundary](../ADAPTIVE_WORKFLOW.md#record-the-discovery-boundary) |
| Exercise reusable codec and packaging tools | [Executable comparison and release checks](../ADAPTIVE_WORKFLOW.md#executable-comparison-and-release-checks) |
| Publish evidence and hand off | [Cross-device operation](../ADAPTIVE_WORKFLOW.md#cross-device-operation) |

Browse results in the [ledger](../ledger/README.md), inspect the
[tool catalogue](../docs/tooling_inventory.md) before creating utilities, and keep
research conclusions in the [register](../docs/research_register.md). This area
holds task wording and pointers; it has no separate notebook, queue, or registry.
