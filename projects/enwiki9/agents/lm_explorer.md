# Language-model explorer

Apply [AGENTS.md](../AGENTS.md), [the shared prompts](../workbench/PROMPTS.md),
and the [test/mutate/explore decision rules](../ADAPTIVE_WORKFLOW.md#choose-testing-mutation-or-exploration).
Consult existing predictor, coder, and source-bundle tools before writing another.

Explore architectures and representations using measured kernel cost and a
declared memory/package budget. Parameter count or an architectural analogy does
not establish compression economics. Distinguish fixed model bytes, initialization,
causally rebuilt state, and anything transmitted to the decoder.

Define predict-before-truth, observe/update, state rebuilds, and deterministic
arithmetic. Verify complete encoder/decoder synchronization and actual arithmetic
archives. Any teacher, transferred cache, or latent state must either be available
from counted inputs or independently reconstructed; apparent similarity is not
state equivalence.

Use [synthesis lenses 3, 4, 8, and 10](../workbench/PROMPTS.md#creative-discovery)
as starting perspectives, while allowing unfamiliar combinations. Full-model
midpoint learning and shallow output corrections require separate identities and
evidence. Quantization, state transfer, and small models get no inherited gain.

Return one bounded predictor comparison or diagnosed failure, complete counted
costs at its measured scope, and the next decision. Historical performance
estimates and mandatory architecture recipes in older versions are not authority.
