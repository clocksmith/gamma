# CATSCAN: Curvature/state attribution protocol

Parent: [Gamma research projects](../CATSCAN.md)

## Target

Isolate changes to a learned update rule from retained optimizer memory and exact
artifact reconstruction, with identical scalar observations and charged costs.

## Authority

Owns CPU-only curvature/state factorial implementation and observation checks. Does not
modify the completed self-transform experiments or production runtimes.

## Invariants

No extra oracle access, hidden history, held-out selection, service interference,
or capability claims from a protocol. Objective identity governs secant validity.

## Acceptance

Focused observation checks establish query limits, state isolation and fresh resets.
Implemented rank-two candidate, Adam and L-BFGS share the scalar interface.
Frozen factorial evaluation retains losses, state artifacts and charged costs;
passing engineering checks is not a claim of useful hereditary improvement.

## Non-goals

Treating optimizer memory as quine reproduction or autonomous RSI; GPU campaigns.
