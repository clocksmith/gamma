# Research projects

These projects keep their own inputs, contracts and reproduction requirements.
They are separate from the installed `gamma` toolkit and applications in `apps/`.

| Project | Boundary and local checks |
| --- | --- |
| [enwiki9](enwiki9/README.md) | Archived compression project. `python3 -m pytest -q` inside its directory runs existing maintenance contracts only. [Retained-output restoration](enwiki9/docs/archive-maintenance/README.md) is separate from research execution. |
| [Algorithm Solver](algorithm_solver/README.md) | Keep `algsolve`, authored catalogue, literals and contracts adjacent. `python3 -m pytest -q` runs parser and requirement checks. |
| [Distillation](distillation/README.md) | Separate translation, embedding and WGSL studies. `python3 -m pytest -q` runs existing CPU decision/rule controls. Training, evaluation and reporting retain their distinct entrypoints. |
| [Reconfiguration](reconfiguration/README.md) | Distinct request-conditioned mechanisms and frozen study contracts. `python3 -m pytest -q` runs existing contract/oracle controls. |
| [Self-transform](self_transform/README.md) | Ten preserved Node ESM studies with their original version names and sibling imports. `npm test` runs their original CPU tests from a foreign working directory. |

The Python front doors configure source-checkout tests; they do not claim
portable wheels or include model/data dependencies. Other projects retain their
existing boundaries. Passing these controls does not qualify a model, compression
score, adaptation gain or hereditary improvement.
