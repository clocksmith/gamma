# Hybrid Distillation (Legacy Name)

The canonical method is now
[`Evidence-Gated Capability Transfer`](EVIDENCE_GATED_CAPABILITY_TRANSFER.md).

`Hybrid distillation` remains a valid narrow term for teacher-assisted
controlled-lane training. It is no longer the umbrella name for data controls,
construction-gold generation, verifier-filtered training, checkpoint selection,
compact rule or router distillation, receipt-bound promotion, and serving-state
reuse.

Use the canonical EGCT document for new experiment design and citations. This
file remains only as a compatibility pointer for older links and receipts.
