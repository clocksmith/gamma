# Smaller prototype implementation acceptance

Executable **0.23.0**, engine **0.26.0**, rules **0.13.0-rc.1-test**.

The six shared areas replace the nineteen hex districts. Two shared Facility
slots per area supply contention. Four tracks replace the overlapping resource
and risk systems. Facilities always operate, upgrades flip one face, Customers
are cards, and all four revealed objectives score once from final holdings.
Research, six Core Actions, independent player kits, negotiation, Headlines,
four Eras, and a separate World Ending remain.

`acceptance.json` identifies the tested source and hashes the retained checks.
All 218 tests passed with zero skips. Fifteen boundary checks and two complete
four-Era UI games passed in Chrome on desktop and mobile, including exports and
publication-subpath links. The public artifact was built locally; no deployment
was performed. The kit is generated component material, not evidence of a human
session or a manufacturing package.

The [registered diagnostic](../../studies/simulation/2026-10-09-smaller-prototype-preregistration.json)
and [result](../../studies/simulation/2026-10-09-smaller-prototype-result.json)
retain 24 completed games per supported player count. All 72 have zero integrity
violations. They include accepted trades and active Ventures. One four-player
game recognizes AGI; no three- or five-player game does. The objective requiring
three Customers has no qualifier in all nine three-player games that reveal it.
These are fixed-policy observations, not balance conclusions. Costs, thresholds,
starting advantages, repeated Customer rewards, and winning-path diversity need
fresh balance and blind-session evidence. No numerical rule was retuned from
these results. Earlier releases, test contracts, and evidence remain unchanged.
