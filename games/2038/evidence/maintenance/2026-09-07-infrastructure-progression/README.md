# Infrastructure progression implementation

The selected order is implemented: Mega-Cluster II, Fusion III, Quantum IV.
Earlier projects remain available; all use ordinary Build with no project chain.
Fusion keeps its former price, immediate award, unique marker and local Power rules.

Quantum costs 4 Runway and 2 Compute at an owned connected Facility, grants 2
Capability and 1 Scrutiny, and completes once per institution. A Facility placed
in the same Build can qualify. Capability caps and permanent awards use existing
scoring. Completion is public snapshot state and a permanent faction-board checkbox.
Quantum reserves no host slot and requires no new shared marker. These numbers
are provisional playtest choices, not a balance result. The inventory now contains
three project reference cards: 115 standard cards plus six foldout aids.
