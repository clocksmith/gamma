# Governance Board tracks

Use printed tracks and cubes. No pen, checkbox, owner inscription, or writable
ledger is supplied. Leave the active objective card visible; it supplies its own
name, criterion, minimum, and cube-record instruction.

## Each institution

- One Mandate cube on the shared score track.
- One cube on the highest Trust milestone awarded track: **0 · 2 · 4 · 6**.
  Start at the highest threshold included in starting Mandate. Move forward
  when a new threshold scores; never move backward during the game.
- One cube on the reusable objective number track. Use the active card's record:
  starting Capability or Customers, Fund gains, Scrutiny added, best successful
  domains, Compute produced, or Deployed (0 No, 1 Yes). Starting values stay
  fixed; other records update as their events occur. Reset for each new Era.
- One cube on **AGI: No · Recognized**. Recognition survives the final Audit.

The objective track prints every integer from 0 to 99. This is a counting surface,
not a resource cap. Current-state objectives use visible board state instead of
another counter. Joint Venture pairs print I–IV on their edges; orient their
construction Era toward the host label so new active ventures can be identified.

## Final comparison

1. Sum the participating institutions' **printed starting Trust**.
2. Compare their final Trust total with that sum plus the number of players.
3. Compare remaining black Audit cubes with the number of players.
4. Inspect the institutions' AGI recognition cubes and use the printed World Ending
   table. Determine the institutional winner from Mandate and ordinary ties.

Compute the result from the visible state. No written setup total or ending
record is required. The current rulebook owns the exact scoring procedure.
